The Program is the domain root. Everything live belongs to this hierarchy:

```text
Program
└── Process
    ├── Server
    └── Client
        ├── traffic
        └── window
```

`Program`, `Process`, `Endpoint`, `Server`, and `Client` are shared runtime
classes. `Endpoint` is the common base of `Server` and `Client`; it is not an
additional ownership level.

## One model in every SDK

SDKs adapt access and authority, but they do not redefine the domain. Repeated
lookup of one live object within an SDK context returns its canonical handle,
so reference equality and `instanceof` remain meaningful.
