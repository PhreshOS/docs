The Program is the domain root. Everything live belongs to this hierarchy:

```text
Program
└── Process
    ├── ServerEndpoint
    │   ├── Context while executing
    │   └── traffic
    └── ClientEndpoint
        ├── Context while executing
        ├── traffic
        └── Window
```

`Program`, `Process`, `Endpoint`, `ServerEndpoint`, `ClientEndpoint`, and
`Service` are shared runtime classes. `Endpoint` is the common base of the two
Endpoint kinds; it is not another ownership level. A Service addresses an
Endpoint without entering the ownership tree.

## Shared contracts

Client, Server, and Node SDKs implement the same contracts for these domain
objects. Repeated lookup of one live entity within the same SDK context returns
its canonical handle, so reference equality and `instanceof` remain meaningful.

Context, Desktop, Window, storage, and appearance are contracts rather than
additional ownership levels. Each belongs to the domain entity or environment
identified on its canonical page.
