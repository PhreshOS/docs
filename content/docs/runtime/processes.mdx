title: Processes
description: Live execution aggregates created from immutable launch intent.

A Process is one live execution aggregate owned by a Program. Its identity,
optional Program-local name, start time, launch options, and parentage remain
fixed for its lifetime.

## Launch

A launch selects which Endpoints start, whether either incarnation is a
Service, Client Window overrides, and immutable string options.

## Create or run

```ts
const process = await program.process.create({
  name: "main",
  server: true,
  client: true,
})
```

| Operation | Contract |
| --- | --- |
| `create(launch)` | Always create a Process |
| `findOrCreate(launch)` | Find an equivalent named Process or create it atomically |
| `run(launch, { signal })` | Create a Process owned by its asynchronous generator |

Reusing a Process name with a different launch rejects.

```ts
const controller = new AbortController()

for await (const event of program.process.run(
  { server: true, client: true },
  { signal: controller.signal },
)) {
  switch (event.event) {
    case "started":
    case "output":
    case "exited":
      console.log(event)
  }
}
```

Aborting the signal, returning early from the generator, or losing its owning
connection exits the Process.

## Endpoints

Every Process owns permanent `server` and `client` handles. The handles remain
addressable while their current Endpoint incarnations are stopped. A Process
ends when its complete execution ends; `exit()` ends all remaining Endpoints.

## Parentage

A Process may retain the immediate Process that created it. Parentage records
creation lineage, not ownership. A Client can traverse parentage only inside its
own Program; the first cross-Program parent is represented as `null`.
