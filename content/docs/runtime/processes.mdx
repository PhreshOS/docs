title: Processes
description: Live execution aggregates created from immutable launch intent.

A Process is one live execution aggregate owned by a Program. Its identity,
optional Program-local name, start time, launch options, and parentage remain
fixed for its lifetime.

## State

| Member | Meaning |
| --- | --- |
| `identity` | Immutable globally unique runtime identity |
| `name` | Optional name unique among the Program's live Processes |
| `startedAt` | Creation instant as a `Date` |
| `server` | Permanent Server Endpoint handle |
| `client` | Permanent Client Endpoint handle |
| `permissions` | Temporary permission assignments retained for this Process lifetime |

`program()` returns the owning Program. `parent()` returns the Process whose
creation call produced this Process, or `null`. `option(name)` reads one
immutable string launch option or returns `undefined`.

`process.permissions` reads and manages only this Process's temporary
permission layer. `get()` and `all()` return assigned values, `allows()` checks
coverage within this layer, and `set()` and `delete()` complete without
returning state. Effective Client authority remains a Context question through
`context.permissions.allows()`.

An exited parent remains available as the same retained Process handle, whose
`exited()` operation returns `true`. `null` means the Process never had a
parent; it does not mean that its parent has exited.

## Program collection

`program.process` addresses only Processes belonging to that Program:

| Operation | Result |
| --- | --- |
| `list()` | Every live Process |
| `first()` | Earliest-started Process or `null` |
| `last()` | Latest-started Process or `null` |
| `find(identityOrName)` | Matching Process or `null` |
| `create(launch?)` | Always create a Process |
| `findOrCreate(launch)` | Find the named Process or atomically create it |
| `exitAll()` | End every Process and return their identities |
| `run(launch?, { signal }?)` | Create a Process owned by an async generator |

`system.process.list()` and `system.process.find(identity)` provide the
System-wide collection.

## Launch

A launch selects a Process name, which declared Endpoints start, per-incarnation
Service roles, Client Window overrides, and immutable string options. Omitting
an Endpoint selection uses its declaration default. Reusing a live Process name
with a different launch rejects.

```ts
const process = await program.process.create({
  name: "main",
  server: { service: true },
  client: true,
  options: { mode: "primary" },
})
```

## Attached run

`run()` yields `started`, `output`, and `exited` in order. Output contains its
`stream` and exact `text`; the final event contains the Process and `Exit`.

```ts
const controller = new AbortController()

for await (const event of program.process.run(
  { server: true, client: true },
  { signal: controller.signal },
)) {
  if (event.event === "started") console.log(event.process.identity)
  if (event.event === "output") console.log(event.stream, event.text)
  if (event.event === "exited") console.log(event.exit)
}
```

Aborting the signal, returning early, or losing the owning connection exits the
Process.

## Operations and events

`exit()` ends the Process and all live Endpoints. `exited()` reports whether it
has ended. An individual Process emits `exit` with `{ status, code, signal }`.
Both `program.process` and `system.process` emit `create` with a Process and
`exit` with the Process plus its exit result.

## Parentage

Parentage records creation lineage, not ownership. A Client can traverse it
only inside its own Program; the first cross-Program parent is represented as
`null`.
