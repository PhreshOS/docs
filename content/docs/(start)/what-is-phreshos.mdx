PhreshOS is an open-source, server-authoritative operating system for running and
managing web-based Programs in a unified web Desktop environment, with native
agent access through shared APIs.

## System and Desktop

One owner runs the System on a machine they control. The System is the source of
truth for installed software, live execution, authentication, persistence,
communication, and access to host capabilities.

The Desktop is that System's graphical representation. It owns browser-local
interaction such as pointer input, keyboard input, viewport measurements,
iframes, and visual transitions. It represents authoritative Window state
without replacing it.

Every Client Endpoint has a System-owned authoritative Window. Its `window`
handle reads, changes, and observes that shared state. A Desktop separately owns
the `localWindow` that physically represents it on one screen, together with
the mechanism that links or detaches the two. Standard windows follow their own
authoritative Window by default; other layers define which state they represent
and whether they begin linked.

## One runtime language

A Program is the stable software identity. Each live execution is a Process.
The Process owns one Server Endpoint and one Client Endpoint. A Service gives a
stable address to an Endpoint that chooses to be reachable.

Official applications and user-created applications enter this same model.
Client, Server, and Node SDKs preserve the same domain contracts; only their
environment, transport, and authority differ.

This gives Programs a shared way to launch and discover execution, exchange
values, persist state, and use System capabilities without rebuilding those
facilities independently.
