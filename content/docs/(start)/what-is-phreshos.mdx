PhreshOS is an open-source, server-authoritative operating system for running and
managing web-based programs in a unified web desktop environment, with native
agent access through shared APIs.

It is self-hosted and single-user: one owner runs it on a machine they control,
and the System keeps its authoritative state there.

The browser is the machine's display, not its authority. The server owns the
truth about Programs, Processes, authentication, persistence, and access to host
resources. A desktop connection represents that truth and provides the local
pointer, keyboard, measurements, iframes, and temporary visual state needed to
interact with it.

```text
Host operating system
└── PhreshOS System
    ├── Server runtime
    │   └── Programs → Processes → Server and Client Endpoints
    └── Web desktop
        └── Windows, taskbar, dialogs, and Client representations
```

## Goal

PhreshOS aims to be the self-hosted application operating system where web
applications, services, and agents operate as one coherent, interactive system.
It provides managed execution, bidirectional communication, and system-wide
identity and authorization, allowing each application to focus on its domain
instead of rebuilding infrastructure.

## Programs are the unit of composition

Applications, background services, tools, and Lemo—the official PhreshOS
agent—are ordinary Programs. Official Programs do not receive a private
architectural path. People, agents, and other Programs use the same public
domain model.

## What PhreshOS does not imply

PhreshOS runs inside an existing host operating system as a per-user service on
macOS, Linux, or Windows. The name does not imply that it replaces the host
kernel. Its concrete meaning is the runtime and remotely accessible System
described in these docs.
