PhreshOS is a server-authoritative operating system for web Programs. You
install a System on a machine you control, open its Desktop in a browser, and
run software as Programs. Each Program can have a Server Endpoint and a
Client Endpoint. This documentation explains those contracts by using them.

You need Node.js `24.15.0` or newer on macOS, Linux, or Windows.

<Steps>

<Step>

### Install the CLI

<Tabs items={["npm", "pnpm", "Bun", "Yarn Classic"]} groupId="package-manager" persist>
  <Tab value="npm">
    ```sh
    npm install --global @phreshos/cli
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Bun">
    ```sh
    bun add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Yarn Classic">
    ```sh
    yarn global add @phreshos/cli
    ```
  </Tab>
</Tabs>

</Step>

<Step>

### Install the System

```sh
phresh system install
```

This installs the official release, registers a per-user native service, and
starts it. It prints the Desktop address. The first visit to that address
creates the owner account.

</Step>

<Step>

### Create a Program

```sh
phresh create
```

The command writes a project with a Server, a Client, and a
`phresh.config.ts`. From the project directory:

```sh
phresh dev
```

That attaches a live Program to the running System for as long as the command
runs. [First Program](/first-program) explains the generated files.

</Step>

</Steps>
