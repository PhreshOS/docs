---
title: Quick start
description: Install PhreshOS, start the System, and create a Program.
icon: Rocket
---

You need Node.js `24.15.0` or newer on macOS, Linux, or Windows.

<Steps>

<Step>

### Install the CLI

<Tabs items={["npm", "pnpm", "Bun", "Yarn Classic"]} groupId="package-manager" persist>
  <Tab value="npm">
    ```sh
    npm install --global @phreshos/cli
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Bun">
    ```sh
    bun add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Yarn Classic">
    ```sh
    yarn global add @phreshos/cli
    ```
  </Tab>
</Tabs>

</Step>

<Step>

### Install the System

```sh
phresh system install
```

This installs the official release, registers a per-user native service, and
starts it. It prints the Desktop address. The first visit to that address
creates the owner account.

</Step>

<Step>

### Create a Program

```sh
phresh create
```

The terminal guides you through the available choices and prints the remaining
instructions.

</Step>

</Steps>
