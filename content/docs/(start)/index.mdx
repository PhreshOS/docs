## Introduction

PhreshOS is a self-hosted operating system for the server it runs on, represented
through a remotely accessible web desktop. It consists of four principal parts:

## Install PhreshOS

You need a supported Node.js installation and a machine on which you can run a
per-user service. PhreshOS stores its state on that machine and adds no telemetry.

<Steps>

<Step>

### Install the CLI

```sh
npm install --global @phreshos/cli
```

</Step>

<Step>

### Install the System

```sh
phresh system install
```

The command installs the official System release, configures its native per-user
service, starts it, and reports the desktop address.

</Step>

<Step>

### Create a Program

```sh
phresh create
cd my-program
bun dev
```

The generated project connects its development Process to your local System.

</Step>

</Steps>
