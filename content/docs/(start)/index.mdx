This guide installs the PhreshOS System as a per-user service and creates a
Program project that runs inside it.

You need Node.js `24.15.0` or newer on macOS, Linux, or Windows.

<Steps>

<Step>

### Install the CLI

<Tabs items={["npm", "pnpm", "Bun", "Yarn Classic"]} groupId="package-manager" persist>
  <Tab value="npm">
    ```sh
    npm install --global @phreshos/cli
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Bun">
    ```sh
    bun add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Yarn Classic">
    ```sh
    yarn global add @phreshos/cli
    ```
  </Tab>
</Tabs>

</Step>

<Step>

### Install the System

```sh
phresh system install
```

The command installs the official release, registers and starts its native
service, then reports the Desktop address.

</Step>

<Step>

### Create a Program

```sh
phresh create
```

Follow the prompts. When creation completes, the terminal displays the
remaining instructions for the options you selected.

</Step>

</Steps>
