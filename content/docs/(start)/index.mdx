This guide installs the System and creates a Program project connected to it.

## Install and create

You need Node.js `24.15.0` or newer and a machine on which you can run a per-user
service. PhreshOS stores its state on that machine.

```sh
node --version
```

<Steps>

<Step>

### Install the CLI

<Tabs items={["npm", "pnpm", "Bun", "Yarn Classic"]} groupId="package-manager" persist>
  <Tab value="npm">
    ```sh
    npm install --global @phreshos/cli
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Bun">
    ```sh
    bun add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Yarn Classic">
    ```sh
    yarn global add @phreshos/cli
    ```
  </Tab>
</Tabs>

</Step>

<Step>

### Install the System

```sh
phresh system install
```

The command installs the official System release, configures its native per-user
service, starts it, and reports the desktop address.

</Step>

<Step>

### Create a Program

```sh
phresh create
```

The generated project connects its development Process to your local System.

</Step>

</Steps>
