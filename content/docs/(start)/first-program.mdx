Create a project with the guided command:

```sh
phresh create
```

The generated Program has one stable kebab-case identity and may contain a
host-side Server, a desktop Client, or both.

## Describe the project

`phresh.config.ts` contains authoring metadata, production locations, build
behavior, and development declarations. The Node Project contract derives
concrete development and production definitions from it.

```ts title="phresh.config.ts"
import { defineConfig } from "@phreshos/core"

export default defineConfig({
  identity: "my-program",
  name: "My Program",
  version: "0.1.0",
  description: "My first PhreshOS Program.",
  buildCommand: "bun run build",
  server: {
    location: "dist/server",
    startCommand: "node main.js",
    development: {
      startCommand: "vite-node server/main.ts",
    },
  },
  client: {
    location: "dist/client",
    development: {
      startCommand: "vite --config vite.client.ts",
    },
  },
})
```

The Client development tool reads the address selected by Project while keeping
port 5200 for direct use:

```ts title="vite.client.ts"
export default defineConfig({
  base: process.env.PHRESHOS_CLIENT_BASE ?? "./",
  server: {
    port: Number(process.env.PHRESHOS_CLIENT_PORT ?? "5200"),
    strictPort: true,
  },
})
```

## Run it

```sh
npm run dev
```

Development attaches the Program to the System for the lifetime of the CLI
connection. The Project assigns an available Client port, starts the declared
development command, and stops it with the development lifecycle. It is an
ordinary runtime Program, not a separate development-only domain object.
