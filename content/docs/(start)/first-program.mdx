Create a Program project with the guided command:

```sh
phresh create
```

The maintained template contains one Program declaration, a Server entry, a
Client entry, and the build tooling that connects them.

## The declaration

`phresh.config.ts` describes the Program project. Node Project resolves it into
the concrete development or production definition consumed by the System.

```ts title="phresh.config.ts"
import { defineConfig } from "@phreshos/core"

export default defineConfig({
  identity: "my-program",
  name: "My Program",
  version: "0.1.0",
  server: {
    location: "dist/server",
    worker: "main.js",
    devCommand: "vite-node server/main.ts",
  },
  client: {
    location: "dist/client",
    devCommand: "vite --config vite.client.ts",
  },
})
```

The Server executes host-side logic. The Client runs in a Desktop iframe. They
are the two Endpoints of one Process and can communicate through their Context
and permanent Endpoint handles.

The Client development server receives its System-selected address through
environment values:

```ts title="vite.client.ts"
import { defineConfig } from "vite"

export default defineConfig({
  base: process.env.PHRESHOS_CLIENT_BASE ?? "./",
  server: {
    port: Number(process.env.PHRESHOS_CLIENT_PORT ?? "5200"),
    strictPort: true,
  },
})
```

## Run it

```sh
cd my-program
npm run dev
```

Development introduces an ordinary runtime Program backed by the project
instead of installed files. The CLI owns the development commands and attached
Process for as long as it runs. Ending the command releases them.
