Installation adds the `phresh` CLI, installs an official System release, and
registers that System with the current user's operating-system service manager.

## Requirements

- Node.js `24.15.0` or newer for the current System release.
- macOS, Linux, or Windows under a normal user account.
- Permission to register a native per-user service.

```sh
node --version
```

<Callout title="CLI runtime">
  The CLI itself supports Node.js `20.10` or newer. The installed System
  currently requires Node.js `24.15.0` or newer.
</Callout>

## Install

<Steps>

<Step>

### Install the CLI

<Tabs items={["npm", "pnpm", "Bun", "Yarn Classic"]} groupId="package-manager" persist>
  <Tab value="npm">
    ```sh
    npm install --global @phreshos/cli
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Bun">
    ```sh
    bun add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Yarn Classic">
    ```sh
    yarn global add @phreshos/cli
    ```
  </Tab>
</Tabs>

</Step>

<Step>

### Install the System

```sh
phresh system install
```

The CLI verifies the release checksum, installs production dependencies in a
versioned directory, selects that release, registers the per-user service, and
starts it.

</Step>

</Steps>

## Service lifecycle

```sh
phresh system status
phresh system start
phresh system stop
phresh system enable
phresh system disable
```

Start and stop affect current execution. Enable and disable control automatic
startup. macOS uses a per-user `launchd` service, Linux uses `systemd --user`
when a user manager is available, and Windows uses a least-privilege per-user
scheduled task.

## System home

Persistent state lives under `~/.phreshos` by default. Set `PHRESHOS_HOME` to an
absolute path before invoking the CLI when you intentionally want another
System home.

```sh
export PHRESHOS_HOME=/absolute/path/to/system-state
phresh system status
```

The CLI and running System must select the same home because that location also
determines the owner-local gateway address.

## Desktop port

Production chooses the first available port from `4300-4399`.
`PHRESHOS_PORT` can select one port, an inclusive range, or an ordered list.

```sh
export PHRESHOS_PORT=4196,4234,5000-5100
phresh system start
```

Development retains Vite's port selection.
