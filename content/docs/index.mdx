PhreshOS Programs can combine a host-side Server with a desktop Client. The
`phresh` CLI creates the project and connects its development process to the
local System.

## Install PhreshOS

Install the CLI, then let it install and start the official System release:

```sh
npm install --global @phreshos/cli
phresh system install
```

The command reports the desktop address when the System is ready.

## Create a Program

Run the guided project creator:

```sh
phresh create
```

Choose where the Program should live, its display name, and the package manager
used to install its dependencies. Then enter the created directory and run its
development command:

```sh
cd my-program
bun dev
```

The generated project contains the complete Server and Client structure. Its
directory name is also its stable Program identity.
