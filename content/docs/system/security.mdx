PhreshOS security separates two questions. Authentication establishes which
browser Connections belong to the System owner. Permissions determine what a
Client Endpoint may see and do once it is running.

The separation matters because a browser Connection and a Program are
different authorities. One Session may authorize several Connections, while
each Client Endpoint receives the permission state of its own Program.

Initial setup signs up the owner. Later browser Connections sign in by attaching
a Session. Server Endpoints and the owner-local Node gateway already execute in
trusted server authority; Client permissions do not apply to them.

The System provides no independent recovery authority above the owner's chosen
authentication method.
