PhreshOS security separates three questions. Authentication establishes which
browser Connections belong to the System owner. Permissions determine which
System capabilities a Program may see and use. The Server execution mode
determines which capabilities its runtime has independently of the System API.

The separation matters because a browser Connection and a Program are
different authorities. One Session may authorize several Connections, while
both Endpoints of a Process receive the permission state of their Program.

Initial setup signs up the owner. Later browser Connections sign in by attaching
a Session. Program permissions constrain System operations in both Client and
Server Endpoints. They do not claim to remove direct host capabilities granted
by a Server's execution mode; a Sandbox is the mode that withholds those
capabilities.

The System provides no independent recovery authority above the owner's chosen
authentication method.
