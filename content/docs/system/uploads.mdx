`system.uploads` is a flat collection of public files owned by the System. It is
a distinct contract from `Storage`; the two are only similar in some read
operations.

## Upload records

`write(content)` stores one `WritableContent` value under an opaque generated key and
returns its complete upload record:

```ts
const upload = await system.uploads.write("Hello from PhreshOS")

console.log(upload.file, upload.size, upload.modifiedAt)
```

The record combines the opaque file key with the same `FileStat` returned by a
Storage file: size in bytes and last modification time as Unix milliseconds.

## Operations

| Operation | Contract |
| --- | --- |
| `path()` | Return the collection's absolute directory |
| `write(content)` | Store `WritableContent` and return its upload record |
| `stat(file)` | Return `FileStat` or `null` |
| `stream(file)` | Open an upload as a byte stream |
| `bytes(file)` | Read an upload as bytes |
| `text(file)` | Read an upload as UTF-8 text |
| `json(file)` | Read and parse an upload as JSON |

The contract intentionally exposes no listing, deletion, or clearing operation.
Completed uploads are public, so a Client can use `stat()`, `stream()`,
`bytes()`, `text()`, and `json()` without a permission. Creating an upload with
`write()` requires `uploads` or `all`. Exposing the native directory with
`path()` requires a matching `storage` scope or `all`.
