`system.network` gives every SDK the same two outbound network capabilities.
Fetch returns a standard `Response`. WebSocket returns a standard
`WebSocket`. PhreshOS controls authority and lifetime without inventing
another request or socket model.

## Fetch

```ts
const response = await system.network.fetch("https://api.example.com/items", {
  headers: { accept: "application/json" },
})

const items = await response.json()
```

The operation accepts `RequestInfo | URL` and an optional `RequestInit`.
Supplying a `Request` preserves its method, headers, body, and abort signal.

## WebSocket

```ts
const socket = await system.network.websocket("wss://example.com/events")

socket.addEventListener("message", event => {
  console.log(event.data)
})
```

The returned socket uses the standard lifecycle, methods, properties, and
events. Acquisition is asynchronous because a Client may need to cross the
System boundary before receiving that socket.

Server and Node sockets close when their owning execution Context or System
connection ends. A Client-owned socket follows the browser frame that
received it.

## Authority

A Program needs a `network` scope covering the requested URL, or `all`. HTTP
and WebSocket schemes are distinct. Permission failure rejects the operation
before the value is returned.

A network scope is a URL without credentials. The hostname may be `*` or a
single leading `*.label`. A path ending in `/**` is a prefix; an omitted path
covers every path. Port `*` covers every port.

This permission governs `system.network.fetch()` and
`system.network.websocket()`. Once a `Response` or WebSocket has been
returned, changing the permission does not revoke that value.
