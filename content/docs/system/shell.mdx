---
title: Shell
description: Run an operating-system command through the shared System contract.
icon: Terminal
---

`system.shell()` runs one shell command and returns its original event generator.
It has the same contract in the Client, Server, and Node SDKs.

```ts
for await (const event of system.shell("npm install", {
  cwd: "/path/to/project",
  env: { NODE_ENV: "production" },
  signal
})) {
  if (event.event === "started") console.log(event.pid)
  if (event.event === "output") console.log(event.stream, event.text)
  if (event.event === "exited") console.log(event.exit)
}
```

The default working directory is the operating-system user's home. Supplied
environment values are merged over the System process environment. Output is
reported exactly as `stdout` and `stderr` chunks; the SDK does not write it to
the caller's terminal.

The generator owns the complete operating-system process tree. Aborting its
signal or closing the generator terminates that tree. A non-zero exit is an
`exited` event, while failures to perform the operation reject iteration.

<Callout title="System operation, not Process creation">
  A shell command does not create a PhreshOS Process. Use a Program's Process
  capability when the work must enter the Program, Process, Endpoint, and
  Service domain model.
</Callout>

## Client permission

A Client can call `system.shell()` only when its effective permissions include
`all`. Server and Node adapters retain full System authority.
