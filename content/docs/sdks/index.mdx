## Shared handle identity

Every SDK imports Core's domain constructors rather than redefining private
handle contracts. Repeated navigation to one live entity in the same SDK
context returns the same canonical handle.

```ts
import { Program } from "@phreshos/node"

const [program] = await system.program.list()
console.log(program instanceof Program) // true
```
