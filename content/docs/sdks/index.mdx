PhreshOS has one domain model and several ways to reach it. Core defines
shared meaning. Client, Server, and Node implement that meaning where they
run. React adapts live contracts to component state. React UI provides the
visual language. The CLI presents Project and System operations to a
terminal.

```ts
import { Program } from "@phreshos/core"
import { System } from "@phreshos/node"

const system = await System.connect()
const program = await system.program.find("notes")

console.log(program instanceof Program)
```

Environment packages export the roots they own: `system`, `context`,
`desktop`, `System.connect`, `Project`. Shared classes and types keep their
Core import path.
