PhreshOS separates contracts from environment adapters. Core defines the
domain model; each environment SDK implements or composes that model without
redefining it. React UI interprets Appearance as environment-neutral React
components without introducing another System or domain model.

## One domain model

Client, Server, and Node implement the same `Program`, `Process`, `Endpoint`,
and `Service` contracts from Core. Their transports and authority boundaries
may differ, but the public entities do not. Shared contracts have one import
path; environment SDKs export only the roots and creators they own. Repeated
navigation to one live entity in the same SDK context returns the same
canonical handle.

```ts
import { Program } from "@phreshos/core"
import { System } from "@phreshos/node"

const system = await System.connect()
const [program] = await system.program.list()

console.log(program instanceof Program) // true

await system.disconnect()
```
