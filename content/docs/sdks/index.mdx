## One domain model

Client, Server, and Node expose the same `Program`, `Process`, `Endpoint`, and
`Service` contracts from Core. Their transports and authority boundaries may
differ, but the public entities do not. Repeated navigation to one live entity
in the same SDK context returns the same canonical handle.

```ts
import { Program, System } from "@phreshos/node"

const system = await System.connect()
const [program] = await system.program.list()

console.log(program instanceof Program) // true

await system.disconnect()
```
