PhreshOS has one domain model and several environment adapters. Core defines
shared meaning. Client, Server, and Node implement that meaning where they run.
React adapts live contracts to component state. React UI provides the visual
language. The CLI presents Project and System operations to a terminal.

## Shared meaning, different boundaries

Client, Server, and Node return the same Core Program, Process, Endpoint,
Service, Connection, and Session domains. The operation may execute locally or
cross a transport, and the caller may have different authority, but the public
contract remains the same.

```ts
import { Program } from "@phreshos/core"
import { System } from "@phreshos/node"

const system = await System.connect()
const program = await system.program.find("terminal")

console.log(program instanceof Program)
```

Environment packages export the roots and constructors they own. They do not
re-export Core under new names or redefine shared domain objects.
