`@phreshos/client` implements PhreshOS contracts for the Client Endpoint
currently executing inside a Desktop iframe. It gives that Client three roots:
its execution `context`, its containing `desktop`, and the shared `system`
view filtered through Client authority.

<Callout title="Peer dependencies">
  Client requires `@phreshos/core`.
</Callout>

```ts
import { context, desktop, system } from "@phreshos/client"
import { Program, Process } from "@phreshos/core"
```

Environment roots come from Client. Shared classes and types retain their Core
import path. Handles returned by Client inherit those Core classes.

## Three views of one execution

`context` answers questions about the current Client incarnation and owns its
inbound communication, paired Server, Window, Local Window, and permission
requests. `desktop` describes the browser environment containing it. `system`
provides the complete System contract, with visible entities and operations
resolved through the Program's permissions.

```ts
const program = await context.program()
const process = await context.process()

console.log(program instanceof Program)
console.log(process instanceof Process)
```

The Client SDK is tied to this Endpoint incarnation. Context-owned operations
and registrations end with it. Knowing another entity's identity never expands
the Client's authority.
