`@phreshos/client` is the adapter for code executing as a Program's Client
Endpoint inside a Desktop. It exposes three roots because three different
owners meet at that position: the global `system`, the current Client
`context`, and the containing `desktop`.

`@phreshos/core` is a peer dependency.

```ts
import { context, desktop, system } from "@phreshos/client"
import { Program, Process } from "@phreshos/core"

const program = await context.program()
const preferences = await desktop.preferences.snapshot()
const appearance = await system.appearance.snapshot()

console.log(program instanceof Program)
```

Shared classes keep their Core import path. Handles returned by Client
inherit those Core classes.

The Client SDK is tied to this Endpoint execution context. Context-owned
operations and registrations end with it. Desktop state may outlive this
Client, and System state is authoritative independently of whether this iframe
is loaded. Knowing another entity's identity never expands the executing
Program's visible scope.
