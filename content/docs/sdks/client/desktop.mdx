---
title: Desktop
description: Read the containing viewport, preferences, and Connection.
---

Client `desktop` is the [Desktop](/system/desktop) that contains this Client
Endpoint. Import it from `@phreshos/client`. It is a separate root from
`context` and `system` because viewport, preferences, and the browser
Connection belong to this representation, not to the Program.

```ts
import { desktop } from "@phreshos/client"

const { size } = await desktop.viewport.snapshot()
const preferences = await desktop.preferences.snapshot()
const connection = await desktop.connection()
```

`desktop.viewport.snapshot()` returns `{ size: { width, height } }` for the
current Desktop workspace. Subscribe to `resize` for complete later snapshots;
changing Desktop scale also changes the logical viewport exposed to Clients.

`desktop.preferences.snapshot()` returns the effective `{ theme, animations,
scale }` value. `update()` accepts any non-empty subset. Use `"default"` for a
field to remove its explicit override and resume its browser or System default:

```ts
await desktop.preferences.update({
  theme: "default",
  animations: false,
  scale: 1.25,
})
```

The `change` event carries the complete effective preference snapshot, not the
partial update that caused it. Theme follows the browser color-scheme
preference by default, animations invert the browser reduced-motion preference,
and scale defaults to `1` within the supported `0.5`–`2` range.

The executing Program needs `desktopConnection` or `authentication` for
`connection()`, and `desktopPreferences` for preference updates. Reading the
viewport and current preferences does not require those mutation permissions.
