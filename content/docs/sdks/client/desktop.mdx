---
title: Desktop
description: Use the browser environment containing the current Client.
---

The Client `desktop` represents the graphical environment containing this
Endpoint. It exposes the current viewport, effective preferences, and—when
permitted—the browser Connection carrying the Desktop.

```ts
import { desktop } from "@phreshos/client"

const { size } = await desktop.viewport.snapshot()
const preferences = await desktop.preferences.snapshot()

console.log(size, preferences)
```

`desktop.viewport` publishes `resize` with a complete `{ size }` snapshot in
CSS pixels. `desktop.preferences` publishes `change` with complete effective
`{ theme, animations }` values. Subscriptions observe later changes; call
`snapshot()` when the current value is needed.

Updating preferences accepts direct values or `"default"` to follow the native
environment and requires `desktopPreferences`.

```ts
await desktop.preferences.update({
  theme: "default",
  animations: true,
})
```

`desktop.connection()` returns the canonical Connection carrying this Desktop.
It requires `desktopConnection` or `connections` and is the same handle that a
visible `system.connection.find()` returns for that identity.

The current Client's Window is not a Desktop-global registry. Its authoritative
and local handles remain under [Context](/sdks/client/context).
