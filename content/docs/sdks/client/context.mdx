---
title: Context
description: Use the current Client execution, paired Server, and Window.
---

Client `context` is the executing Client Endpoint's
[Context](/runtime/context). Import it from `@phreshos/client`. It exists
only while this execution context is running.

```ts
import { context } from "@phreshos/client"

const program = await context.program()
const process = await context.process()
```

The Client position adds:

- `context.server` — the paired Server Endpoint of the same Process
- `context.window` — the Client Endpoint's authoritative Window
- `context.presentation` — this Desktop's applied representation of that Window
- `context.permissions` — the executing Program's stored assignment, and
  owner requests

```ts
await context.window.setTitle("Notes")
const status = await context.server.ask("status.read")
```

`stop()` ends this Client execution context. Communication on `context` is
documented under [Communication](/runtime/communication). Window operations
are documented under [Desktop](/system/desktop).
