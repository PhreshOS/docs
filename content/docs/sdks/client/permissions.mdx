---
title: Permissions
description: Inspect authority and request an owner's decision from a Client.
---

Permissions belong to the Program. The Client Context is how the executing
Client reads that state and asks the owner to change it. The catalog and
visibility rules are documented under [Permissions](/system/permissions).

```ts
import { context } from "@phreshos/client"

const allowed = await context.permissions.allows("uploads")

if (!allowed) {
  await context.permissions.request("uploads")
}
```

`get` returns the stored assignment without applying fallback authority.
`allows` reports whether the stored permission permits the requested
capability. `request` prompts the owner, replaces the stored permission, and
returns that canonical value. `timeout(milliseconds)` selects another
deadline for the prompt.

`program.permissions` is the administration API: `get`, `all`, `allows`,
`set`, and `delete`. Those operations require `all`.
