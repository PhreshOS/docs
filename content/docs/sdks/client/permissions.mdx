---
title: Permissions
description: Inspect stored Client authority and request owner decisions.
---

Client permissions expand authority for later Client operations. Permission
names and their value domains come from Core's closed catalog; a Program cannot
invent either one.

## Context permissions

`context.permissions` reads and checks the Program's authoritative stored
permissions. Declared entries are applied during Program creation and
installation according to the [permission persistence rules](/system/security#permissions).

| Operation | Result |
| --- | --- |
| `get(name)` | Exact stored assignment: a canonical list, `false`, or `null` |
| `allows(name, value?)` | Whether current stored authority covers the request |
| `request(name, value?)` | Requested canonical list, `false`, or `null` |
| `timeout(milliseconds).request(...)` | The same request with another deadline |

```ts
import { context } from "@phreshos/client"

const scope = ["https://api.example.com"] as const

if (!await context.permissions.allows("network", scope)) {
  const granted = await context.permissions.request("network", scope)
  console.log(granted)
}
```

Requests wait for up to two minutes by default. Every call asks the owner, even
when current authority already covers a narrower request. Approval replaces
that exact permission and returns its canonical value. Denial or dismissal
returns `false` or `null` without changing storage.

## Program permissions

`program.permissions` directly manages the only permission state belonging to
that Program: `storage/permissions.json`.

| Operation | Result |
| --- | --- |
| `get(name)` | Stored canonical value |
| `all()` | Every stored value indexed by permission name |
| `allows(name, value?)` | Whether stored values cover the request |
| `set(name, value)` | `Promise<void>` |
| `delete(name)` | `Promise<void>` |

```ts
const program = await context.program()

await program.permissions.set("network", ["https://api.example.com"])
console.log(await program.permissions.get("network"))
await program.permissions.delete("network")
```

Client access to `program.permissions` itself requires `all`. Server and Node
retain owner-level System access.

## Canonical values

`true` is assignment and request shorthand for a permission's default list. It
is resolved before storage or return. Arrays are unordered sets and duplicate
values are removed. `false` records denial, while `null` represents no stored
assignment and belongs to `delete()` rather than `set()`.

An explicit assignment has priority over `all`, which supplies unassigned
permissions. Consequently, approving a narrower exact request genuinely
restricts that capability.

[Security](/system/security) defines every permission, its value grammar,
creation-time seeding, fallback authority, and exact operation coverage.
