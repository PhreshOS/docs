---
title: Subscription hooks
description: Observe future events, questions, and answers in React.
---

Subscription hooks register for the same future-only streams as
`subscribe()`, and clean up when the component unmounts. They do not replay
current state. Until a matching event arrives, they return `undefined`.

## useSubscribe

Use `useSubscribe` when a component needs the latest value from an event
stream rather than a complete current snapshot:

```tsx
const exit = useSubscribe(process, "exit")

return <output>{exit?.status ?? "Process is running"}</output>
```

The event name and returned message are inferred from the supplied Core
handle. Targets with an application-defined fallback event contract also
accept arbitrary event names.

An optional third argument projects the message before React stores it and may
be synchronous or asynchronous. Without an event name, the projector receives
`{ event, message }`. Changing the target or event replaces the registration;
changing only the projector does not reconnect it.

Use a domain state hook when the component needs a current value immediately.
`useSubscribe` is deliberately future-only and does not call a read operation
to reconstruct state.

## useSubscribeAsks

`useSubscribeAsks(target, project)` observes questions sent **from** an
Endpoint. Pass its `traffic` surface, not the Endpoint itself. The capture
contains the event, correlation `questionId`, destination, and payload:

```tsx
const question = useSubscribeAsks(process.client.traffic, capture => ({
  event: capture.event,
  questionId: capture.questionId,
  payload: capture.message.payload,
}))
```

The destination is `null` when it lies outside the observer's visible scope.
This is traffic observation; it neither sends nor answers the question.

## useSubscribeAnswers

`useSubscribeAnswers(target, project)` similarly observes answers sent from a
Server Endpoint's `traffic` surface:

```tsx
const answer = useSubscribeAnswers(process.server.traffic, capture => ({
  questionId: capture.questionId,
  outcome: capture.message.outcome,
}))
```

`outcome` is either `{ success: true, result }` or
`{ success: false, error }`. Observation does not consume the answer or alter
the original asker's Promise.

All three hooks own exactly one persistent SDK registration while mounted and
remove it when the component unmounts or its target changes. Their projection
result is local React state; returning a value from the projector does not
publish or answer anything across the Endpoint boundary.

The communication contract is documented under
[Communication](/runtime/communication).
