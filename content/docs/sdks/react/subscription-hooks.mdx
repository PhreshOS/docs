---
title: Subscription hooks
description: Observe future events, questions, and answers in React.
---

Subscription hooks register for the same future-only streams as
`subscribe()`, and clean up when the component unmounts. They do not replay
current state.

```tsx
useSubscribe(process.server, "changed", value => {
  setCount(value)
})
```

`useSubscribe(target, event, subscriber)` follows one named event.
`useSubscribe(target, subscriber)` follows every event as
`{ event, message }`.

`useSubscribeAsks` follows questions originating from an Endpoint.
`useSubscribeAnswers` follows answers originating from a Server Endpoint.

The communication contract is documented under
[Communication](/runtime/communication).
