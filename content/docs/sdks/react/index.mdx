---
title: Overview
description: Bring existing PhreshOS contracts and event lifecycles into React.
---

`@phreshos/react` adapts existing PhreshOS values to React. Providers place
root contracts in a component tree, state hooks combine an initial read with
future domain events, and subscription hooks retain the latest observed
message.

React remains a view of the underlying contracts. The package does not create
another System, mirror authority, or turn remote state into an application-owned
source of truth.

<Callout title="Peer dependencies">
  React requires `@phreshos/core` and `react`.
</Callout>

Install the environment SDK that supplies the contracts separately. A Desktop
Client usually provides them from `@phreshos/client`:

```tsx
import { context, desktop, system } from "@phreshos/client"
import {
  ContextProvider,
  DesktopProvider,
  SystemProvider,
} from "@phreshos/react"
```

## Supplying the roots

The three providers are independent because Context, Desktop, and System are
independent contracts. Nesting only chooses which subtree can read each value.

```tsx
<SystemProvider system={system} fallback={null}>
  <DesktopProvider desktop={desktop} fallback={null}>
    <ContextProvider context={context} fallback={null}>
      <Application />
    </ContextProvider>
  </DesktopProvider>
</SystemProvider>
```

Inside the tree, root hooks return the supplied contract, state hooks follow a
selected domain handle, and subscription hooks observe future communication.
