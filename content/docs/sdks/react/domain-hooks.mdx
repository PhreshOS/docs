---
title: Domain hooks
description: Follow live Program, Process, Endpoint, Window, and related state.
---

Domain hooks take an existing Core handle and follow it while the component
is mounted. Until the first read completes, they return `undefined`. They do
not create Programs or Processes.

```tsx
const programState = useProgramState(program)
const processState = useProcessState(process)
const endpointState = useEndpointState(process.server)
const windowState = useWindowState(process.client.window)
```

| Hook | Follows |
| --- | --- |
| `useProgramState` | `installed` and live `processes` |
| `useProcessState` | `exited` |
| `useEndpointState` | `exists` |
| `useServiceState` | `exists` for a Service handle |
| `useWindowState` | the complete authoritative `WindowState` |
| `useConnectionState` | Connection `connected` and `session` |
| `useSessionState` | Session `valid` and `connections` |

These snapshots are derived from the same reads and events documented under
[Runtime](/runtime) and [System](/system).
