---
title: Providers
description: Supply Context, System, and Desktop contracts to a React subtree.
---

A provider makes one existing PhreshOS root available to descendants. It may
resolve initial values and subscribe to changes needed by its hooks. It does
not own or replace the supplied root.

Every provider accepts `children`, its corresponding contract, and an optional
`fallback`. The fallback defaults to `null` and remains visible until that
provider's initial values resolve. A failed read reaches the nearest React
error boundary.

## ContextProvider

`ContextProvider` resolves the Program, Process, and parent belonging to one
Client Context before rendering its children.

```tsx
<ContextProvider context={context} fallback={<Loading />}>
  <Application />
</ContextProvider>
```

`useContext()` returns the complete Client Context. `useProgram()`,
`useProcess()`, and `useParent()` return the resolved execution identities.

## SystemProvider

`SystemProvider` supplies the System handle. `useSystem()` returns it.
`useSystemAppearance()` follows `system.appearance`.

```tsx
<SystemProvider system={system}>
  <Themed />
</SystemProvider>
```

The System may come from Client or from Node. `ContextProvider` and
`DesktopProvider` require Client Context and Desktop values.

## DesktopProvider

`DesktopProvider` supplies the Desktop handle. `useDesktop()` returns it.
`useDesktopViewport()`, `useDesktopPreferences()`, and
`useDesktopConnection()` follow those Desktop sources.

The three providers are independent. Supply only the roots the subtree
actually uses.
