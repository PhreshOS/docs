`@phreshos/server` implements the shared PhreshOS contracts for a Program's
executing Server Endpoint.

```ts
import { context, system } from "@phreshos/server"
```

## Entry points

| Export | Contract |
| --- | --- |
| `context` | Current Server execution Context |
| `system` | Complete global System |

## Context

`context` provides the executing Program and Process, paired Client Endpoint,
immutable options, communication, and question handlers.

```ts
context.answer("status.read", () => ({ ready: true }))
```

## Authority

The Server retains complete System authority. Local capabilities such as
`fetch()` and `shell()` preserve the System contract while executing locally
and remain bound to the Server connection's lifetime.

The same SDK contract applies whether the Server runs as a host process or a
System-owned Worker.

## Domain handles

The SDK exports Core's `Program`, `Process`, `Endpoint`, `ServerEndpoint`,
`ClientEndpoint`, `Service`, `ServerService`, and `ClientService` constructors.
These preserve Core reference identity within this SDK context.

See [Endpoints](/runtime/endpoints) for Server execution modes and
[Communication](/runtime/communication) for questions, subscriptions, and
event semantics.
