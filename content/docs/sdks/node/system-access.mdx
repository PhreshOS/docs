---
title: System access
description: Use complete System capabilities through a trusted Node connection.
---

A connected Node `System` exposes the complete Core System contract with owner
authority. It can navigate every Program, Process, Connection, Session, and
Service and use Storage, uploads, Appearance, Network, and shell without a
Client permission boundary.

```ts
import { System } from "@phreshos/node"

const system = await System.connect()
const program = await system.program.find("terminal")
const process = await program?.firstProcess()

console.log(program?.name, process?.identity)
```

The operation contracts remain those documented under [System](/system). Node
does not rename them or provide parallel Node-only domain objects.

## Local work under connection ownership

When crossing the gateway would not change meaning, Node performs work with
its own platform facilities. Fetch and WebSocket return the standard values,
shell supervises a native command tree, and native Storage starts from the
operating-system user's home.

```ts
const response = await system.network.fetch("https://api.example.com/status")

for await (const event of system.shell("node --version")) {
  if (event.event === "output") console.log(event.text)
}
```

Local execution does not move ownership away from the connected System.
Disconnecting still ends attached sockets, streams, subscriptions, and command
trees.

Repeated navigation through one connection returns the same canonical handle.
The same domain identity reached through another Node connection is represented
by another JavaScript object.
