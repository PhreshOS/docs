---
title: System access
description: Use the complete System contract from an owner connection.
---

The connected `System` object is the same [System](/system) contract as
Client and Server. Owner-local connections are trusted: they are not filtered
by a Program permission state.

```ts
import { System } from "@phreshos/node"

const system = await System.connect()

const program = await system.program.find("notes")
const processes = await system.process.list()

await system.disconnect()
```

`system.shell()` and native `system.storage` run in the Node process. They
remain the Core `shell()` and `Storage` contracts.

`system.execute()` is the JSON catalog documented under
[Execute](/sdks/core/execute). The CLI's runtime commands use this connection.

Programs, Processes, Endpoints, Services, Connections, Sessions, Appearance,
uploads, and networking still use the connected System. Only capabilities
whose Core contract has an equivalent owner-local implementation—currently
shell and native Storage—execute locally without changing their public
meaning.

`system.logs` and each visible `program.logs` support the same read-only SQL
queries and live `log` event described under [Logs](/system/logs).

Node has no Endpoint Context, so it cannot create a permission request.
Owner-local code can inspect or assign a Program's permissions through
`program.permissions`, and can list, observe, and resolve pending Endpoint
requests through `system.permissions`.
