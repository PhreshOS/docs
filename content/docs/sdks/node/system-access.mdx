A connected Node `System` implements the complete Core System contract with
owner-level authority.

```ts
import { System } from "@phreshos/node"

const system = await System.connect()
```

## Shared capabilities

| Member | Capability |
| --- | --- |
| `program` | List, find, create, and observe Programs |
| `process` | List, find, and observe Processes |
| `service(key)` | Address one Server or Client Service |
| `storage` | Access the native filesystem |
| `uploads` | Read and create uploads |
| `appearance` | Read and replace System Appearance |
| `fetch()` | Perform an outbound standard request |
| `websocket()` | Open a standard WebSocket |
| `shell()` | Stream an operating-system command |

```ts
const program = await system.program.find("terminal")
const process = await program?.process.first()

console.log(program?.name, process?.identity)
```

The complete operation contracts live under [System](/system). Node does not
rename or narrow them.

## Owner-local execution

When crossing the gateway would make no observable difference, Node executes a
capability directly while keeping it attached to the connection lifetime:

- `fetch()` uses the Node standard Fetch implementation.
- `websocket()` creates the Node standard WebSocket.
- `shell()` supervises the native command tree.
- `storage` enters at the operating-system user's home directory.

```ts
const response = await system.fetch("https://api.example.com/status")
console.log(response.status)

for await (const event of system.shell("node --version")) {
  if (event.event === "output") console.log(event.text)
}
```

Local execution is an implementation choice beneath the same contract. The
returned values, errors, cancellation, and disconnection behavior remain tied
to this System connection.

## Canonical handles

Repeated navigation to the same live entity through one connection returns the
same canonical handle. Handles inherit Core constructors:

```ts
import { Program } from "@phreshos/core"

const first = await system.program.find("terminal")
const second = await system.program.find("terminal")

console.log(first === second)
console.log(first instanceof Program)
```

Canonical identity is connection-local. A handle from another connection
represents the same domain entity but is not the same JavaScript object.
