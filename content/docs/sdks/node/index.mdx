---
title: Overview
description: Connect external Node.js code to PhreshOS and operate Program projects.
---

`@phreshos/node` has two Node-owned responsibilities: creating a connection to
a running System and turning a local Program project into runtime, development,
installation, or release definitions.

## Install

<Tabs items={["npm", "pnpm", "Bun", "Yarn Classic"]} groupId="package-manager" persist>
  <Tab value="npm">
    ```sh
    npm install @phreshos/node
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm add @phreshos/node
    ```
  </Tab>
  <Tab value="Bun">
    ```sh
    bun add @phreshos/node
    ```
  </Tab>
  <Tab value="Yarn Classic">
    ```sh
    yarn add @phreshos/node
    ```
  </Tab>
</Tabs>

<Callout title="Peer dependencies">
  Node requires `@phreshos/core`.
</Callout>

```ts
import { Project, System } from "@phreshos/node"
import { Program, Process } from "@phreshos/core"
```

Core is a peer dependency. Node exports its connection and project creators;
shared domain constructors and contracts remain imported from Core.

## Public surface

| Export | Responsibility | Reference |
| --- | --- | --- |
| `System` | Create and close an owner-local System connection | [Connection](/sdks/node/connection) |
| `Project` | Load and execute one Program project | [Project](/sdks/node/project) |
| `resolveHome()` | Resolve the selected absolute System home | [Connection](/sdks/node/connection) |
| `gatewayAddress()` | Derive its local socket or named-pipe address | [Connection](/sdks/node/connection) |

The connected System implements the same Core contract as Client and Server.
Its only additional operation is `disconnect()`, which owns the lifetime of
this external connection.
