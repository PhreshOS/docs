---
title: Overview
description: Connect external Node.js code to the System and operate Program projects.
---

`@phreshos/node` connects trusted external Node.js code to a running System and
turns a local Program project into runtime or release definitions. These are
two Node-specific entry points built on the same Core contracts.

## Install

<Tabs items={["npm", "pnpm", "Bun", "Yarn Classic"]} groupId="package-manager" persist>
  <Tab value="npm">
    ```sh
    npm install @phreshos/node
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm add @phreshos/node
    ```
  </Tab>
  <Tab value="Bun">
    ```sh
    bun add @phreshos/node
    ```
  </Tab>
  <Tab value="Yarn Classic">
    ```sh
    yarn add @phreshos/node
    ```
  </Tab>
</Tabs>

<Callout title="Peer dependencies">
  Node requires `@phreshos/core`.
</Callout>

```ts
import { Project, System } from "@phreshos/node"
import { Program, Process } from "@phreshos/core"
```

`System` creates an owner-local external connection. `Project` owns authoring,
build, development, installation, and packaging around one
`phresh.config.ts`. Shared domain handles and types remain Core values.
