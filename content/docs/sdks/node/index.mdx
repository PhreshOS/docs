---
title: Overview
description: Connect external Node.js code to a System and operate local Program projects.
---

`@phreshos/node` serves code that is outside every Endpoint. It exposes the
same complete System contract available inside Server Endpoints, but the
caller owns an external connection rather than an execution Context. It also
provides the `Project` authoring API for building, running, installing, and
packaging local Program projects.

`@phreshos/core` is a peer dependency.

```ts
import { Project, System } from "@phreshos/node"

const system = await System.connect()
const project = await Project.open()

for await (const event of await project.start(system)) {
  console.log(event)
}

await system.disconnect()
```

There is no Context: Node is not an executing Endpoint and therefore has no
paired role, launch options, or Context-owned registrations. The connection
itself owns pending work and subscriptions obtained through it.
