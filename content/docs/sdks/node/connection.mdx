---
title: Connection
description: Connect to a running System through the owner-local gateway.
---

`System.connect(home?)` opens an owner-local connection to a running System
and returns a `System` handle. `disconnect()` closes that connection and
aborts every attached operation it owns.

```ts
import { System } from "@phreshos/node"

const system = await System.connect()
const programs = await system.program.list()
await system.disconnect()
```

The optional `home` is a System home directory. Omission uses
`PHRESHOS_HOME` or `~/.phreshos`, the same default as the CLI.

On POSIX the gateway is a Unix-domain socket in that home. On Windows it is
an owner-created named pipe. This is not a browser
[Connection](/system/security/authentication) and not a Session. It is an external
trusted transport to the same System.

`gatewayAddress` and `resolveHome` are available when a tool needs those
paths without connecting.

The connection owns the handles, pending operations, subscriptions, command
streams, and locally implemented capabilities obtained through it.
`disconnect()` releases that work. Later operations through the disconnected
`System` reject because the connection is closed.

Disconnecting does not stop the native System service and does not alter
Programs, Processes, or persistent System state. It ends only this external
owner connection.
