---
title: Connection
description: Connect Node.js code to one owner-local PhreshOS System.
---

`System.connect()` returns a complete System implementation whose work belongs
to one external Node connection. The connected object implements Core's
`System` contract and adds `disconnect()` to end that connection.

```ts
import { System } from "@phreshos/node"

const system = await System.connect()
console.log(await system.program.list())

await system.disconnect()
```

The Node connection is trusted owner-local transport. It is not a browser
`Connection` and has no authentication `Session`.

## Selecting the System home

The optional `home` argument identifies which local System to reach:

```ts
const system = await System.connect("/absolute/system/home")
```

Selection uses the explicit argument first, then `PHRESHOS_HOME`, then
`.phreshos` under the operating-system user's home. A custom value must be
absolute. `resolveHome(home?)` exposes the same resolution without connecting.

`gatewayAddress(home)` derives the local transport address for an already
resolved home. POSIX uses `gateway.sock` in that home; Windows uses a named pipe
derived from the canonical home identity. Most applications need neither
helper directly.

## Owned lifetime

The connection owns every handle, pending operation, subscription, network
value, command stream, and local capability obtained through it.
`disconnect()` closes the gateway and releases that attached work. Later
operations reject because the System connection is closed.

Disconnecting does not stop the System service or alter Program state. It ends
only this external path into the System.
