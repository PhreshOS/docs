---
title: Execution environments
description: Run the same Server contract in a supervised process or System-owned Worker.
---

A Server declaration chooses how its code is hosted. This choice changes the
connection adapter beneath `@phreshos/server`; it does not change the Server
Context or System contract seen by application code.

## Supervised process

```ts
server: {
  location: "dist/server",
  startCommand: "node main.js",
}
```

`startCommand` starts an operating-system process supervised by the System.
The Server SDK connects through the process IPC channel supplied to it.

## System-owned Worker

```ts
server: {
  location: "dist/server",
  entryFile: "main.js",
}
```

`entryFile` loads an ECMAScript module in a Node.js Worker owned by the System.
The SDK connects through the Worker's parent channel.

In both environments, application code uses the same imports:

```ts
import { context, system } from "@phreshos/server"

console.log((await context.program()).identity)
console.log(await system.uploads.path())
```

Context identity, domain handles, System capabilities, communication values,
and lifecycle remain equal. Ending either host ends the Server Endpoint
incarnation and publishes the same Endpoint lifecycle.
