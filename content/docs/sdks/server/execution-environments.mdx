---
title: Execution environments
description: Command, Worker, and Sandbox as one Server Endpoint contract.
---

A Server declaration chooses exactly one production execution mechanism. The
Server SDK and Endpoint contract are the same in each. What differs is the
host authority available outside the System API.

| Declaration | What runs |
| --- | --- |
| `command` | A supervised operating-system process |
| `worker` | An ECMAScript module in a Node.js Worker |
| `sandbox` | A bundled module in a capability-contained JavaScript runtime |

```ts
server: {
  location: "dist/server",
  worker: "main.js",
}
```

Development always uses `server.devCommand` with the project's
development tooling.

A `command` or `worker` Server retains the host capabilities of its process.
A `sandbox` Server has no ambient host access; its only outside capabilities
are permission-constrained System operations. Permissions constrain the
System API in every mode. See [Security](/system/security) and
[Program configuration](/sdks/core/program-configuration).
