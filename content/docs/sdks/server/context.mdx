title: Context
description: Use capabilities belonging to the currently executing Server Endpoint.

---

`context` is the execution-local root for the current Server Endpoint. Its
shared execution operations match the Client Context; its Server-specific
capabilities are the paired Client Endpoint and question answering.

```ts
import { context } from "@phreshos/server"
```

## Execution

| Operation | Result |
| --- | --- |
| `context.program()` | Current Program |
| `context.process()` | Current Process |
| `context.name()` | Process name or `null` |
| `context.parent()` | Parent Process or `null` |
| `context.option(name)` | Immutable launch option or `undefined` |
| `context.isService()` | Whether this Server incarnation is a Service |
| `context.stop()` | End this Server Endpoint incarnation |

```ts
const [program, process, parent] = await Promise.all([
  context.program(),
  context.process(),
  context.parent(),
])

console.log(program.identity, process.identity, parent?.identity)
```

## Paired Client

`context.client` is the permanent Client Endpoint address belonging to the same
Process. Its identity remains stable while Client incarnations start and stop.

```ts
if (await context.client.exists()) {
  context.client.publish("document.changed", { revision: 2 })
}
```

The handle also exposes Client traffic, lifecycle observation, Window state,
start, stop, Service state, and readiness.

## Answer questions

Only the executing Server Context registers answerers because questions target
Server Endpoints.

```ts
const cleanup = context.answer("status.read", ({ from, payload }) => {
  return { ready: true, requestedBy: from, payload }
})
```

`answer(event, answerer)` returns a cleanup function. The answerer receives the
same `{ from, payload }` envelope as a Context subscription and may return its
result directly or through a Promise. Running the cleanup stops future handling
for that registration.

## Publish and subscribe

```ts
context.publish("server.ready")

const cleanup = context.subscribe("job.start", message => {
  console.log(message.from, message.payload)
})
```

`from` is `null` when no visible Endpoint handle can represent the sender.
[Communication](/runtime/communication) defines publications, captures,
traffic, questions, answers, and binary boundary values.

## Lifetime

Calling `context.stop()` ends the current Server incarnation. If its paired
Client remains live, the Process may continue. Stopping releases Context-owned
answerers, subscriptions, and pending operations; a future Server incarnation
receives a new Context.
