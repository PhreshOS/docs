`@phreshos/server` implements PhreshOS contracts for a Program's current Server
Endpoint incarnation. It exposes the execution `context` and the complete
trusted `system` root.

## Install

<Callout title="Peer dependencies">
  Server requires `@phreshos/core`.
</Callout>

```ts
import { context, system } from "@phreshos/server"
import { Program, Process } from "@phreshos/core"
```

Server exports only the roots it owns. Shared domain classes and types remain
Core imports, and handles returned by Server inherit those classes.

## Trusted execution

`context` identifies the current Server, receives its messages, exposes its
paired Client, and registers answers. `system` provides the same complete
contract used by Client and Node, but Server execution is trusted and is not
narrowed by Program permissions.

The Context begins and ends with one Server incarnation. A future incarnation
receives a new Context even though the permanent Server Endpoint handle remains
the same.
