`@phreshos/server` is the adapter for a Program's Server Endpoint. It exposes
the complete Core `system` contract and the current Server `context` in the
three execution modes: a supervised `command` process, a System-owned
`worker`, and a capability-contained `sandbox`.

`@phreshos/core` is a peer dependency.

```ts
import { context, system } from "@phreshos/server"

context.answer("counter.read", async () => ({ value: 1 }))

const program = await context.program()
const appearance = await system.appearance.snapshot()
```

There is no `desktop` root. A Server is not a Desktop representation. It can
read and change the paired Client's authoritative Window through
`context.client.window`.
