---
title: System access
description: Use complete System capabilities from a trusted Server Endpoint.
---

Server `system` implements the complete Core System contract with trusted
authority. Program permissions describe Client scope and therefore do not
apply to Server execution.

```ts
import { system } from "@phreshos/server"

const programs = await system.program.list()
const connections = await system.connection.list()
```

The root provides Program, Process, Connection, and Session collections;
Service addresses; Storage and uploads; Appearance; Network; and shell
execution. Each operation has the same name, input, result, and lifecycle as in
the Client and Node implementations. See [System](/system) for those contracts.

## Local implementation, shared behavior

When no semantic boundary requires transport, the Server SDK uses facilities
available in its host environment. Fetch and WebSocket use platform-standard
implementations, shell supervises a native command tree, and Storage can access
the filesystem directly.

```ts
const response = await system.network.fetch("https://api.example.com/status")

for await (const event of system.shell("node --version")) {
  if (event.event === "output") console.log(event.text)
}
```

This local execution remains owned by the Server Context. When the Endpoint
stops, its attached requests, sockets, streams, and command trees are released.

`system.service(key)` returns `ServerService` or `ClientService` according to
the `endpoint` coordinate. Only the Server Service supports questions.
