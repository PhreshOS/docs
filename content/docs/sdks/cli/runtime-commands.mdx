title: Runtime commands
description: Operate Programs, Processes, Endpoints, Services, and Windows through Execute.

Runtime commands are the [Execute](/sdks/core/execute) catalog as human-facing
commands. They connect through Node to a running System and invoke the same
public handles as SDK code. The domain meaning lives under [Runtime](/runtime)
and [Desktop](/system/desktop).

```sh
phresh program list
phresh program inspect --program notes
phresh process create --program notes --client
phresh endpoint ask --program notes --process main --endpoint server --event status.read
phresh service search --name editor
phresh window inspect --program notes --process main
```

Add `--json` for the complete result as one JSON value.

| Command | Execute operation |
| --- | --- |
| `program list \| inspect \| agent \| getLaunch \| setLaunch \| logs \| wait` | `program.*` |
| `process list \| inspect \| create \| findOrCreate \| exit \| wait` | `process.*` |
| `endpoint inspect \| start \| stop \| waitReady \| ask \| publish \| wait \| waitLifecycle` | `endpoint.*` |
| `service list \| search \| inspect \| waitReady \| ask \| publish \| wait \| waitLifecycle \| waitDiscovery` | `service.*` |
| `window inspect \| move \| resize \| setGeometry \| minimize \| maximize \| setTitle \| setHeader \| setFrame \| setTransaction \| raise \| wait` | `window.*` |
| `operation list \| describe` | `operation.*` |
| `execute` | raw JSON request |

```sh
phresh execute '{"$domain":"program","$operation":"list"}'
phresh operation describe --domain endpoint --operation ask
```

`program list` also accepts `--installed-only`, `--search`, `--limit`, and
`--offset` as presentation filters around the Execute result.

## Processes and Endpoints

A Process name is local to its Program, so commands that use a name also need
`--program`. Endpoint creation flags translate into the same Launch fields as
the SDK. Service flags select the role of that execution context; `--no-server`
and `--no-client` keep the corresponding Endpoint stopped.

```sh
phresh process create \
  --program notes \
  --name main \
  --server \
  --client-service \
  --option document=welcome.txt
```

Endpoint `wait` observes application publications, while `waitLifecycle`
observes `start` and `stop`. CLI payloads use JSON even though direct SDK
communication can preserve additional JavaScript and binary values.

## Windows

Window commands mutate the authoritative Window. Geometry accepts finite
pixels or the same workspace-relative expressions accepted by Core, and
`setGeometry` commits position and size together.

```sh
phresh window set-geometry \
  --program notes \
  --process main \
  --x 0 \
  --y 0 \
  --width 100% \
  --height 100%
```

The camel-case operation names and the kebab-case terminal aliases are both
shown by `phresh describe`.
