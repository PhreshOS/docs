---
title: Runtime commands
description: Operate Programs, Processes, Endpoints, and Windows through Execute.
---

Runtime commands are the [Execute](/sdks/core/execute) catalog as human-facing
commands. They connect through Node to a running System and invoke the same
public handles as SDK code. The domain meaning lives under [Runtime](/runtime)
and [Desktop](/system/desktop).

```sh
phresh program list
phresh program inspect --program notes
phresh process create --program notes --client
phresh endpoint ask --program notes --process main --endpoint server --event status.read
phresh window inspect --program notes --process main
```

Add `--json` for the complete result as one JSON value.

| Command | Execute operation |
| --- | --- |
| `program list \| inspect \| agent \| getLaunch \| setLaunch \| logs \| wait` | `program.*` |
| `process list \| inspect \| create \| findOrCreate \| exit \| wait` | `process.*` |
| `endpoint inspect \| start \| stop \| waitReady \| ask \| publish \| wait \| waitLifecycle` | `endpoint.*` |
| `window inspect \| move \| resize \| setGeometry \| minimize \| maximize \| changeTitle \| changeHeader \| raise \| wait` | `window.*` |
| `operation list \| describe` | `operation.*` |
| `execute` | raw JSON request |

```sh
phresh execute '{"$domain":"program","$operation":"list"}'
phresh operation describe --domain endpoint --operation ask
```

`program list` also accepts `--installed-only`, `--search`, `--limit`, and
`--offset` as presentation filters around the Execute result.
