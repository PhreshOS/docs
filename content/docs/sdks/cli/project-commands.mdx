---
title: Project commands
description: Create, run, install, and package a local Program project.
---

These commands operate on a Program project directory. Run and install go
through the Node [Project](/sdks/node/project) API and a connected System.
The meaning of a Program is documented under [Programs](/runtime/programs).

```sh
phresh create
phresh create notes --package-manager bun
phresh init --server --client
```

`create` writes a complete Server and Client project from the maintained
starter. In an interactive terminal it asks for choices that were not supplied
as options. `--no-install` leaves dependency installation to the caller.

`init` writes `phresh.config.ts` for an existing package and derives available
metadata from `package.json`. Server and Client flags choose the Endpoint
shape; `--force` replaces an existing configuration.

```sh
phresh dev
phresh start
phresh pack
phresh install
phresh install --run
phresh uninstall
```

`dev` resolves the development definition. `start` runs the optional build and
uses the production definition. Both attach one Process to the terminal, relay
Endpoint output, and exit that Process when the command ends.

`pack` runs the build, validates declared files, and writes `program.json`, a
versioned release archive, and its SHA-256 checksum.

`install` without a name builds and installs this project. A name installs a
verified official release. `--run` overrides the Program's installation
default and creates one Process using its Endpoint defaults. Without `--run`,
the definition's `installLaunch` decides whether installation starts a Process.
Startup remains independent and runs only when the System boots. On install, `--purge` removes previous
installed Program storage before replacement. On uninstall it also removes
Processes, persistent storage, and the runtime Program; ordinary uninstall
removes only the installed form.

Pass Process options as `--run-option-<name>=<value>`:

```sh
phresh dev --run-option-document=welcome.txt
```

These values become the immutable string options returned by
`context.options()` in both Endpoints.
