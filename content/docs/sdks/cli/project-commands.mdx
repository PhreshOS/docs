---
title: Project commands
description: Create, run, install, and package a Program project.
---

Project commands operate on source code and `phresh.config.ts`. When an
operation needs the running System, the CLI creates a temporary Node SDK
connection and owns it for the command lifetime.

## Creating a project

```sh
phresh create example-program --package-manager bun
cd example-program
```

`create [directory]` generates the maintained full Program template. In an
interactive terminal it asks for missing choices. `--no-install` creates the
project without installing its dependencies.

`phresh init` adds a typed `phresh.config.ts` to an existing project. It derives
identity, version, and description from `package.json`; Server and Client flags
select the Endpoint shape. `--force` replaces an existing configuration.

## Running attached code

```sh
phresh dev
phresh start
```

Both commands create an attached Process whose lifetime belongs to the terminal
command. `dev` resolves development Endpoint declarations. `start` runs the
optional production build and uses production declarations. Endpoint output is
written to the terminal, and ending the command ends the Process.

Launch options use open names so a Program can define its own values:

```sh
phresh dev --run-option-document=example.txt
```

## Installing and uninstalling

Without a name, `phresh install` builds and installs the current project. A
name selects a verified official release.

```sh
phresh install
phresh install terminal --run
```

`--run` asks the System to create a Process from the installed Program before
configured startup runs. `--purge` removes previous installed Program storage
as part of replacement; it does not delete source-project storage.

```sh
phresh uninstall terminal
phresh uninstall terminal --purge
```

Ordinary uninstallation removes the installed form while preserving retained
runtime state and storage. `--purge` removes all Program-owned installed state.

## Packaging

```sh
phresh pack
```

`pack` runs `buildCommand`, validates declared files, and creates the resolved
`program.json`, versioned release archive, and SHA-256 checksum. This is the
same Project packaging contract exposed by [Node Project](/sdks/node/project).
