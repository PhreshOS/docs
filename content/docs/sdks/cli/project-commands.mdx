---
title: Project commands
description: Create, run, install, and package a local Program project.
---

These commands operate on a Program project directory. Run and install go
through the Node [Project](/sdks/node/project) API and a connected System.
The meaning of a Program is documented under [Programs](/runtime/programs).

```sh
phresh create
phresh create notes --package-manager bun
phresh init --server --client
```

`create` writes a complete Server and Client project from the maintained
starter. `init` writes `phresh.config.ts` for an existing package.

```sh
phresh dev
phresh start
phresh pack
phresh install
phresh install --run
phresh uninstall
```

`dev` and `start` attach a Process to the terminal. Ending the command exits
that Process. `pack` builds production files and writes the release archive.
`install` without a name installs this project. A name installs a verified
official release. `--run` creates a Process before startup. `--purge` deletes
existing installed storage on install, or Processes, data, and runtime state
on uninstall.

Pass Process options as `--run-option-<name>=<value>`:

```sh
phresh dev --run-option-document=welcome.txt
```
