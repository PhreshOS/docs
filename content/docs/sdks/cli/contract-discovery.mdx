---
title: Contract discovery
description: Read the CLI command model as human help or structured data.
---

Every CLI command is registered from one explicit contract containing its
path, aliases, arguments, options, guidance, examples, System requirement, and
output shape. Human help and machine discovery read that same source.

## Human help

```sh
phresh process create --help
```

Help explains the selected command for a terminal reader. Invalid paths,
options, and values show the relevant help instead of guessing intent.

## Structured discovery

```sh
phresh describe
phresh describe process create
phresh describe --all --json
```

`describe [path...]` returns one command description. `--all` recursively
includes descendants, and `--json` emits one structured JSON value.

The result identifies the command path, name, aliases, description, arguments,
options, guidance, examples, whether a System is required, output schema, and
child commands. Option descriptions preserve value requirements, repetition,
choices, and defaults. Output metadata describes both the structured value and
its human presentation.

```sh
phresh describe endpoint ask --json
```

Discovery itself needs no running System. The returned contract tells tooling
whether the selected command does. A Program's `agent.md` remains responsible
only for that Program's own tool language; it does not redefine the CLI.

## Execute discovery

`phresh describe` continues to describe the complete CLI, including project and
System-management workflows owned by the CLI. Runtime operations also expose
their JSON contracts through Execute:

```sh
phresh execute '{"$domain":"operation","$operation":"list"}'
phresh execute '{"$domain":"operation","$operation":"describe","domain":"endpoint","operation":"ask"}'
```

Human-facing runtime commands reuse the corresponding Execute operation
descriptions while retaining CLI-specific options such as search and paging.
The same operation catalog is also available as commands:

```sh
phresh operation list
phresh operation describe --domain endpoint --operation ask --json
```
