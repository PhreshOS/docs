---
title: System commands
description: Install and control the native System service.
---

`phresh system` owns the System release and the native per-user service.
Programs and Processes are top-level runtime commands.

```sh
phresh system install
phresh system status
phresh system version
phresh system start
phresh system stop
phresh system enable
phresh system disable
phresh system uninstall
```

`install` and `uninstall` accept `--purge` to delete the System home. The
full host contract is documented under [Installation](/installation).
