---
title: System commands
description: Install and control the native System service.
---

`phresh system` owns the System release and the native per-user service.
Programs and Processes are top-level runtime commands.

```sh
phresh system install
phresh system status
phresh system version
phresh system start
phresh system stop
phresh system enable
phresh system disable
phresh system uninstall
phresh system logs --statement 'select * from logs order by createdAt desc limit 100'
```

`install` and `uninstall` accept `--purge` to delete the System home. The
install command verifies the official release, installs its production
dependencies, selects the version, registers the per-user native service, and
starts it. `status` reports both service state and the Desktop address.

`start` and `stop` control the current service execution. `enable` and
`disable` control automatic startup. `uninstall` removes the registered
service and installed System release; its `--purge` option also deletes the
System home. The full host contract and platform behavior are documented under
[Installation](/installation).

`logs` is the running-System operation in this command family. It accepts a
read-only SQL statement against the System `logs` table and optional bound
values through `--values`. It requires the [`logs` permission](/system/security/permissions)
and is documented with the underlying [System log contract](/system/logs).
