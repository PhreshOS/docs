---
title: Overview
description: Use PhreshOS projects, runtime domains, and System lifecycle from a terminal.
---

The `phresh` CLI translates terminal commands into the same Project and System
contracts used by the SDKs. It has three jobs: work with a local Program
project, operate the running domain model, and manage the native System
service.

<Tabs items={["npm", "pnpm", "Bun", "Yarn Classic"]} groupId="package-manager" persist>

    ```sh
    npm install --global @phreshos/cli
    ```
  </Tab>
  <Tab value="pnpm">

    ```sh
    pnpm add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Bun">
    ```sh
    bun add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Yarn Classic">
    ```sh
    yarn global add @phreshos/cli
    ```
  </Tab>
</Tabs>

Node.js `20.10` or newer is required for the CLI. The current System release
requires Node.js `24.15.0` or newer. See [Installation](/installation).

```sh
phresh create
phresh dev
phresh install
phresh system status
phresh program list
phresh execute '{"$domain":"operation","$operation":"list"}'
```

Runtime commands render lists or labeled fields for people by default. Add
`--json` to receive the complete result as one JSON value. `phresh execute`
accepts and returns JSON directly.

`phresh describe` inspects a command. `phresh describe --all --json` returns
the complete machine-discoverable command contract.
