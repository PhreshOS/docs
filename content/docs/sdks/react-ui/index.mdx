`@phreshos/react-ui` provides the material, layout, and accessible controls
used by PhreshOS interfaces. Its visual contracts accept the corresponding
System values directly. The package does not depend on a Client or Server
runtime and does not own application state.

React and React DOM are peer dependencies because the application and React
UI must share one React runtime.

```tsx
import { Button, Surface } from "@phreshos/react-ui"

<Surface>
  <Button>Continue</Button>
</Surface>
```

Without a provider, components use `defaultAppearance` and follow the
browser's visual preferences. `UIProvider` supplies Appearance, Preferences,
and direction for a subtree. A complete System Appearance can be passed
directly; React UI uses the visual fields it owns.

Color and material are independent. `color` accepts an Appearance color and
resting level such as `background:base` or `primary:soft`, or a direct CSS
color. `size` accepts `xsmall`, `small`, `medium`, `large`, or `xlarge`.
`disabled` prevents activation and focus; `pending` prevents activation while
retaining focus.

Controls use the shared contracts that fit their role. Most accept `size` and
`color`; Surface-based controls also accept material options. Individual
component pages state the exact capabilities they expose.
