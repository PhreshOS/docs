title: Appearance
description: Supply and resolve the visual source used by React UI components.
---

React UI owns the visual `Appearance` its components consume: colors,
spacing, radius, shadow, material, and transaction. The System's Appearance
has the same visual shape and can be passed directly. Wallpapers remain
outside the React UI contract. React UI also accepts one complete set of
environment preferences and one concrete direction.

See [Appearance](/system/appearance) for the System document.

## Resolution

Without a provider, `useAppearance()` returns `defaultAppearance`,
`usePreferences()` follows the browser's effective theme and reduced-motion
choice, and `useDirection()` follows the document. `UIProvider` supplies
these inputs independently to one subtree. Each supplied property establishes
only its own boundary. An omitted property continues through the nearest
higher provider or its own fallback. A provider with no properties changes
nothing.

```tsx
<UIProvider
  appearance={appearance}
  preferences={{ theme: "dark", animations: true }}
>
  <Application />
</UIProvider>
```

React UI Preferences are one complete `{ theme, animations }` value. A
provider either supplies that complete value or inherits it. A System Desktop
preferences snapshot can be passed directly; Desktop-only values such as
`scale` remain outside the React UI contract. Appearance follows the same
whole-value rule.

`useBrowserPreferences()` exposes the browser fallback.
`useThemedValue(value)` selects the light or dark branch using the effective
preferences.

```tsx
function Foreground() {
  const appearance = useAppearance()
  const colors = useThemedValue(appearance.colors)

  return <span style={{ color: colors.foreground }}>Current foreground</span>
}
```

## Direction

Direction is separate from Appearance. Supplying `direction="ltr"` or
`direction="rtl"` makes `UIProvider` create a DOM direction boundary using
`display: contents`. When direction is omitted, no boundary is created.

`useDocumentDirection()` observes `<html dir>` and returns `"ltr"` or
`"rtl"`. A missing value, `auto`, or any unsupported value resolves to
`"ltr"`. `useDirection()` returns the nearest explicitly supplied provider
value, or the document direction when there is none.

```tsx
<UIProvider direction="rtl">
  <Application />
</UIProvider>
```

## Derived levels

Appearance provides one concrete spacing value, one radius value, and named
colors. React UI derives levels around those values:

| Level | Numeric factor |
| --- | ---: |
| `xsmall` | `0.25` |
| `small` | `0.5` |
| `medium` | `1` |
| `large` | `1.5` |
| `xlarge` | `2` |

`useScale(value)` returns this complete numeric scale for any concrete
number. `resolveSpacing()` and `resolveRadius()` resolve one semantic level,
number, or CSS value against an Appearance. When these resolver functions are
called directly, a semantic spacing or radius needs a concrete Appearance
argument. `resolveRadius("full")` is a fully rounded corner.

Colors use `subtle`, `soft`, `base`, `strong`, and `intense`. `base`
preserves the source. The other levels derive lighter or darker treatments
from the same color.

```tsx
function BrandScale() {
  const blue = useColor("#4c9cff")
  return <span style={{ background: blue.soft }}>Soft blue</span>
}
```

`useColor()` and `useScale()` each accept one concrete value and return its
memoized derived scale.

A semantic color combines an Appearance color with a level, such as
`"primary:soft"`. A direct CSS color can be supplied when the caller already
owns the concrete value.

The named sources are `background`, `foreground`, `default`, `primary`,
`secondary`, `success`, `warning`, `danger`, and `info`. Theme names select
the source palette. Components that need luminance or contrast inspect the
resolved colors.

## Material and motion

`appearance.material` supplies opacity, backdrop, grain, grain amount,
distortion, and saturation independently for each theme. A component can
override only the material values it needs through its `material` prop. Color
selects paint; material selects substance. Each override may be a scale level
or a number; numbers are clamped to the Appearance material limits.

`appearance.transaction` provides the duration and easing used for material,
control-state, and overlay changes. When preferences disable animations,
React UI uses a duration of zero without modifying Appearance.
