---
title: Appearance
description: Provide and resolve the visual source used by React UI components.
---

React UI consumes Core's `Appearance` contract directly. It does not define a
React-specific copy. The value accepted by `AppearanceProvider`, the
`defaultAppearance` re-exported by React UI, and the snapshots exposed by
[`system.appearance`](/system/appearance) all have the same Core contract.

The System owns the live value. React UI owns how a supplied value is inherited,
resolved for a Theme, and consumed by components.

## Contract

Appearance is one complete unresolved visual source:

```ts title="appearance.ts"
type Appearance = Readonly<{
  colors: AppearanceColors
  spacing: ThemedValue<number>
  radius: ThemedValue<number>
  shadow: ThemedValue<AppearanceShadow, AppearanceShadow>
  material: ThemedValue<AppearanceMaterial, AppearanceMaterial>
  signInWallpaper: ThemedValue<string | null, string | null>
  desktopWallpaper: ThemedValue<string | null, string | null>
}>
```

| Value | Meaning in React UI |
| --- | --- |
| `colors` | Named sources from which components resolve paint and contrast |
| `spacing` | Source value for semantic spacing levels |
| `radius` | Source value for semantic radius levels |
| `shadow` | Source for components that explicitly own elevation; it is not part of Surface |
| `material` | Source values for opacity, backdrop, grain, distortion, and saturation |
| `signInWallpaper`, `desktopWallpaper` | Core values retained in the complete contract; React UI does not load them implicitly |

Every field remains unresolved until its consumer needs a concrete Theme
branch. The Core contract, its supported ranges, and the System operations that
replace the live value are documented under [System Appearance](/system/appearance).

## Resolution

| API | Result |
| --- | --- |
| `useAppearance()` | Nearest complete unresolved Appearance, or `defaultAppearance` |
| `useTheme()` | Nearest explicit Theme, or the browser's current color scheme |
| `useResolveTheme(value)` | The supplied themed value resolved for the effective Theme |
| `AppearanceProvider` | Optional Appearance and Theme source for one React subtree |
| `defaultAppearance` | Core's complete environment-neutral default Appearance |

Without a provider, `useAppearance()` returns `defaultAppearance` and
`useTheme()` reactively follows `prefers-color-scheme`. During server rendering,
the Theme snapshot is `light`; the browser becomes authoritative on the client.

An inner provider inherits each omitted value independently. Overriding Theme
does not replace Appearance, and overriding Appearance does not stop the
inherited Theme from changing.

## Derived scales

`useScale` and `useColor` have the same role. Each accepts one explicit concrete
value, memoizes the complete visual scale derived from it, and returns that
scale. Neither hook reads Appearance or resolves a Theme by itself.

### Numeric scale

| API | Input | Result |
| --- | --- | --- |
| `useScale(value)` | Concrete number | `NumericScale`, containing every `ScaleLevel` |

| Level | Factor | Result for `useScale(12)` |
| --- | ---: | ---: |
| `xsmall` | `0.25` | `3` |
| `small` | `0.5` | `6` |
| `medium` | `1` | `12` |
| `large` | `1.5` | `18` |
| `xlarge` | `2` | `24` |

```tsx title="numeric-scale.tsx"
import { useScale } from "@phreshos/react-ui"

export function SpacingSummary() {
  const values = useScale(12)

  return <p>{values.small}px · {values.medium}px · {values.large}px</p>
}
```

Saturation is the one material value scaled around the neutral multiplier of
`1`; its levels scale the distance from `1`, rather than the complete number.

### Color scale

| API | Input | Result |
| --- | --- | --- |
| `useColor(value)` | Concrete CSS color | `ColorScale`, containing every `ColorLevel` |

| Level | Derivation |
| --- | --- |
| `subtle` | 25% source color mixed toward white |
| `soft` | 60% source color mixed toward white |
| `base` | Source color unchanged |
| `strong` | 82% source color mixed toward black |
| `intense` | 68% source color mixed toward black |

```tsx title="color-scale.tsx"
import { useColor } from "@phreshos/react-ui"

export function ColorSample() {
  const values = useColor("#4c9cff")

  return <span style={{ background: values.soft }}>Soft blue</span>
}
```

## Component values

Components accept semantic values when they need a value derived from the
current Appearance, and direct values when the caller already owns the concrete
result.

| Contract | Semantic value | Direct value | Default when applicable |
| --- | --- | --- | --- |
| `Color` | `appearanceColor:colorLevel` | CSS color | `background:base` |
| `Spacing` | `ScaleLevel` | Number or CSS spacing | Component-specific |
| `Radius` | `ScaleLevel` | Number or CSS radius | Component-specific |

The named Appearance colors are `background`, `foreground`, `primary`,
`secondary`, `success`, `warning`, `danger`, and `info`.

`resolveSpacing(value, appearance)` and `resolveRadius(value, appearance)` are
parallel non-hook resolvers. A direct number or CSS value passes through. A
semantic level is derived from the corresponding Appearance source and
therefore requires an Appearance value.

## Read resolved values

```tsx title="appearance-summary.tsx"
import {
  useAppearance,
  useResolveTheme,
  useTheme,
} from "@phreshos/react-ui"

export function AppearanceSummary() {
  const appearance = useAppearance()
  const theme = useTheme()
  const foreground = useResolveTheme(appearance.colors.foreground)

  return <p style={{ color: foreground }}>
    Theme: {theme} · spacing: {appearance.spacing.light}px
  </p>
}
```

Theme names select branches; they do not imply that one resolved color is
lighter than another. Visual behavior that depends on luminance must use the
resolved colors themselves.

## Ownership

React UI neither reads nor updates System Appearance. A System-connected
application obtains the shared Core value through its environment SDK and
passes it to `AppearanceProvider`. A standalone application can use
`defaultAppearance` or provide another complete Appearance.
