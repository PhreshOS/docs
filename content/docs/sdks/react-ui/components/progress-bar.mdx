title: Progress Bar
description: Communicate determinate progress or ongoing activity.
---

Use `ProgressBar` to communicate how an operation is advancing. It reports
status but does not let the user change the value.

```tsx
<ProgressBar label="Uploading archive" value={64} />
```

## Determinate progress

`value` is interpreted within `minValue` and `maxValue`. Their defaults are
`0` and `100`. Values outside the range are constrained by the underlying
progress contract, and the rendered fill represents the resulting percentage.

```tsx
<ProgressBar
  label="Files copied"
  value={3}
  minValue={0}
  maxValue={8}
  valueLabel="3 of 8"
/>
```

Use `formatOptions` when the generated value should follow a different
`Intl.NumberFormat` representation. Use `valueLabel` when the operation has a
more useful domain-specific description.

## Indeterminate progress

Use `indeterminate` when an operation is active but its remaining work cannot
be measured. In this state the progress bar does not expose a current numeric
value.

```tsx
<ProgressBar aria-label="Connecting to System" indeterminate />
```

The moving indicator follows animation preferences. When animations are
disabled, the component retains a static indeterminate indicator without
inventing a numeric value.

## Selected props

| Prop | Default | Use |
| --- | --- | --- |
| `value` | `0` | Set determinate progress. |
| `minValue` | `0` | Set the beginning of the range. |
| `maxValue` | `100` | Set the end of the range. |
| `indeterminate` | `false` | Represent activity whose progress is unknown. |
| `valueLabel` | generated percentage | Provide explicit visible and accessible value text. |
| `formatOptions` | percent | Format generated value text. |
| `color` | `default:base` | Select the indicator color. |
| `size` | `medium` | Derive typography and track thickness. |

Provide `aria-label` or `aria-labelledby` when there is no visible `label`.
