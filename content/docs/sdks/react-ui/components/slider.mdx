`Slider` represents one numeric value. It supports pointer, touch, keyboard,
and form participation.

<SliderShowcase />

`value` and `defaultValue` are numbers. `minValue` defaults to `0`.
`maxValue` defaults to `100`. `step` defaults to `1`. `orientation` is
`horizontal` or `vertical`. `onChange` fires while the value moves;
`onChangeEnd` fires when the interaction finishes. `label` and `description`
follow the shared field contract. `size` and `color` follow the shared
control contract.
