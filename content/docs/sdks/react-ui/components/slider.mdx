---
title: Slider
description: Select and submit one numeric value with pointer, touch, and keyboard input.
---

`Slider` represents one number inside a range. React Aria owns the accessible
range behavior, keyboard interaction, pointer and touch dragging, native form
value, and reset behavior; React UI supplies its Appearance-aware track and
thumb.

`value` and `onChange` create a controlled Slider. `defaultValue` supplies an
uncontrolled initial value. `onChange` reports every movement;
`onChangeEnd` reports the committed value after keyboard or pointer
interaction.

`minValue`, `maxValue`, and `step` define the range. Values are clamped to its
limits. Arrow keys move by one step, while Home and End select the limits.
`orientation` defaults to horizontal and may be vertical. `name` connects the
value to native form submission.

The default control color is `"default:base"`; `size` controls track and thumb
geometry. Slider does not accept `material` or `radius` because its track and
thumb are range geometry rather than Surface containers. Its thumb motion
still follows Appearance transaction and animation preferences.
