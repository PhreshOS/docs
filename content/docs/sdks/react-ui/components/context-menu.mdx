---
title: Context Menu
description: Open a Menu from the platform context-menu gesture.
---

<ContextMenuShowcase />

Wrap the target in `ContextMenu.Trigger` and place the shared [`Menu`](./menu)
contract inside `ContextMenu.Content`.

```tsx
<ContextMenu>
  <ContextMenu.Trigger>
    <ProcessItem />
  </ContextMenu.Trigger>
  <ContextMenu.Content>
    <Menu aria-label="Process actions">
      <Menu.Item id="show">Show</Menu.Item>
      <Menu.Item id="close">Close</Menu.Item>
    </Menu>
  </ContextMenu.Content>
</ContextMenu>
```

The component owns dismissal and reopening behavior while leaving the trigger's
content intact. Use [`DropdownMenu`](./dropdown-menu) when a visible Button
should open the commands.
