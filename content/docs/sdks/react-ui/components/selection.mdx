Choose the component according to the kind of value being edited:

| Component | Use it for |
| --- | --- |
| `Checkbox` | An independent boolean choice or an item in a multi-selection. |
| `Switch` | A setting that turns on or off. |
| `RadioGroup` and `Radio` | One visible choice from a small set. |
| `Select` | One choice from a list that should remain collapsed until opened. |

## Checkbox and Switch

Both report a boolean directly to `onChange`. Checkbox additionally supports an
indeterminate presentation for a partially selected group.

```tsx
<Checkbox
  label="Include completed Processes"
  checked={includeCompleted}
  onChange={setIncludeCompleted}
/>

<Switch
  label="Automatic updates"
  checked={automaticUpdates}
  onChange={setAutomaticUpdates}
/>
```

Use Checkbox when the value represents a choice. Use Switch when changing the
value represents enabling or disabling a setting.

## Radio groups

`RadioGroup` owns the selected value, label, feedback, and shared presentation.
Each `Radio` contributes one value.

```tsx
<RadioGroup
  label="Release channel"
  value={channel}
  onChange={setChannel}
>
  <Radio value="stable" label="Stable" />
  <Radio value="preview" label="Preview" />
</RadioGroup>
```

Radio is not a standalone boolean control; keep Radio options inside their
group.

## Select

Select accepts string-valued options. An option can be unavailable without
being removed from the list.

```tsx
<Select
  label="Region"
  value={region}
  onChange={setRegion}
  options={[
    { value: "eu", label: "Europe" },
    { value: "us", label: "United States" },
    { value: "local", label: "Local", disabled: true },
  ]}
/>
```

The menu supports keyboard navigation, typeahead, and scrolling for long lists.
`onChange` receives the selected string or `null`.

## Shared props

The selection controls share `label`, `description`, `errorMessage`, `size`,
`color`, `material`, `shadow`, and `disabled`. They can be controlled with
`checked` or `value`, or initialized for uncontrolled use with the corresponding
`defaultChecked` or `defaultValue` prop.
