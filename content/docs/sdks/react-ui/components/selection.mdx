title: Selection
description: Represent boolean, exclusive, and listed choices with accessible controls.
---

Checkbox, Switch, Radio, and Select express different selection domains while
sharing color, size, material, disabled state, labels, and feedback.

<SelectionShowcase />

`Checkbox` is an independent boolean field. It accepts `checked`,
`defaultChecked`, `indeterminate`, and `readOnly`.

`Switch` is a boolean field with a sliding indicator.

`RadioGroup` owns exclusive choice. `Radio` is one option inside that group.

`Select` chooses one value from `options`, each `{ value, label }`.
