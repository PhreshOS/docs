React UI overlays keep each public role as an explicit component. The root owns
open state and lifecycle, the trigger owns the interaction that opens it, and
the content owns its positioned Surface. Semantic content remains separate
from positioning.

## Popover

A `Popover` presents non-modal content relative to a trigger.
`Popover.Content` owns placement and material. `Popover.Dialog` supplies the
accessible content boundary inside it.

The content follows Appearance material, shadow, radius, and transaction
defaults. Its `color`, `material`, `shadow`, and `radius` properties are the
same Surface contracts used elsewhere.

## Menus

`Menu` owns a keyboard-navigable collection of commands or selectable options.
It does not decide how that collection opens. A `DropdownMenu` opens it from a
button. A `ContextMenu` opens the same contract from a context request.

`Menu` accepts `color` and `size`. `Menu.Item`, `Menu.Section`,
`Menu.Header`, and `Menu.Separator` compose the collection.

## Dialog

A `Dialog` presents modal content. `Dialog.Backdrop` owns dismissal and
overlay paint. `Dialog.Content` owns the Surface. Header, title, description,
body, footer, and close are explicit parts.

`AlertDialog` uses the same parts. Its backdrop defaults to
`isDismissable={false}` and `isKeyboardDismissDisabled={true}`.

## Tooltip

A `Tooltip` describes its trigger. `Tooltip.Trigger` is a Button.
`Tooltip.Content` is a Surface with placement.
