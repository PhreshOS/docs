---
title: Scroll Area
description: A native scrolling viewport with React UI scrollbars.
---

`ScrollArea` is a native scrolling viewport with locally owned React UI
scrollbars. `axis` is `vertical` by default, or `horizontal` or `both`.
`onScroll` and `viewportRef` address the scrolling viewport.

<ScrollAreaShowcase />

Scrollbar thickness and inset come from Appearance spacing. Direction follows
`useDirection()` or an explicit `dir`.
