title: Layout
description: Arrange children with Flexbox or Grid without adding visual paint.
---

`Flex` and `Grid` are layout containers. They render a `div`, forward its ref,
and add no material, color, border, padding, or shadow. Use them when the
parent-child relationship itself owns the layout.

Both accept `align`, `justify`, `gap`, and `inline`. Alignment uses `start`,
`center`, `end`, `stretch`, or `baseline`. Justification uses `start`,
`center`, `end`, `between`, `around`, or `evenly`. `gap` accepts an
Appearance-derived scale level, a pixel number, or an explicit CSS value.

## Flex

Flex adds `direction` and `wrap`. Direction is `row`, `row-reverse`,
`column`, or `column-reverse`. `wrap` is `true`, `false`, or `"reverse"`.
`inline` uses `inline-flex`.

## Grid

Grid adds `columns`, `rows`, and `flow`. `columns` and `rows` accept an equal
track count or a native CSS track expression. `inline` uses `inline-grid`.
