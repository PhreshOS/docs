`Flex` and `Grid` express layout without adding material, color, padding, a
border, or a shadow. Use them when the parent-child relationship owns the
layout and the children own their own presentation.

## Flex layouts

Use `Flex` for content arranged primarily along one axis.

```tsx
<Flex align="center" justify="between" gap="medium">
  <span>Connection</span>
  <Button size="small">Reconnect</Button>
</Flex>
```

Columns and wrapping use the same component:

```tsx
<Flex direction="column" gap="small">
  <Input label="Name" />
  <Input label="Email" />
</Flex>

<Flex wrap gap="small">
  {tags.map(tag => <Button key={tag}>{tag}</Button>)}
</Flex>
```

## Grid layouts

Use a number for equal columns, or provide a native CSS track expression when
the tracks have different roles.

```tsx
<Grid columns={3} gap="medium">
  {items.map(item => <Surface key={item.id}>{item.name}</Surface>)}
</Grid>

<Grid columns="minmax(12rem, 1fr) 2fr" gap="large">
  <Navigation />
  <MainContent />
</Grid>
```

## Selected props

| Prop | Components | Use |
| --- | --- | --- |
| `gap` | Both | Use an Appearance scale such as `small`, a pixel number, or a CSS value. |
| `align` | Both | Set cross-axis alignment. |
| `justify` | Both | Distribute children along the main axis. |
| `inline` | Both | Render `inline-flex` or `inline-grid`. |
| `direction`, `wrap` | `Flex` | Control the primary axis and line wrapping. |
| `columns`, `rows`, `flow` | `Grid` | Define tracks and automatic placement. |

Prefer the semantic `start` and `end` values over physical left and right
alignment so the layout remains direction-neutral.
