---
title: Layout
description: Arrange children with Flexbox or Grid without adding visual paint.
---

`Flex` and `Grid` are layout containers. They render a `div`, forward its ref,
and add no material, color, border, padding, or shadow. Use them when the
parent-child relationship itself owns the layout.

Both accept `align`, `justify`, `gap`, and `inline`. Alignment uses `start`,
`center`, `end`, `stretch`, or `baseline`. Justification uses `start`, `center`,
`end`, `between`, `around`, or `evenly`.

`gap` accepts an Appearance-derived scale level, a pixel number, or an explicit
CSS value.

## Flex

Flex adds `direction` and `wrap` to the shared layout values.

<ComponentPreview>
  <Preview>
    <Flex align="center" justify="between" gap="medium" style={{ width: 320 }}>
      <Surface style={{ padding: 12 }}>First</Surface>
      <Surface style={{ padding: 12 }}>Second</Surface>
      <Surface style={{ padding: 12 }}>Third</Surface>
    </Flex>
  </Preview>
  <PreviewCode>

    ```tsx
    <Flex align="center" justify="between" gap="medium">
      <Surface>First</Surface>
      <Surface>Second</Surface>
      <Surface>Third</Surface>
    </Flex>
    ```

  </PreviewCode>
</ComponentPreview>

`direction` accepts the four CSS flex directions. `wrap` accepts a boolean or
`"reverse"`.

## Grid

Grid adds `columns`, `rows`, and automatic `flow`.

<ComponentPreview>
  <Preview>
    <Grid columns={3} gap="medium" style={{ width: 320 }}>
      <Surface style={{ padding: 12 }}>One</Surface>
      <Surface style={{ padding: 12 }}>Two</Surface>
      <Surface style={{ padding: 12 }}>Three</Surface>
    </Grid>
  </Preview>
  <PreviewCode>

    ```tsx
    <Grid columns={3} gap="medium">
      <Surface>One</Surface>
      <Surface>Two</Surface>
      <Surface>Three</Surface>
    </Grid>
    ```

  </PreviewCode>
</ComponentPreview>

A numeric track count becomes equal `minmax(0, 1fr)` tracks. A string remains
an ordinary CSS track expression. Named props own their corresponding layout
behavior; unrelated native `div` props and styles pass through.

If an existing element can express the same relationship itself, another
layout container is unnecessary.
