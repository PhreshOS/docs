`Surface` is the material-owning primitive of React UI. It combines a host
element, material paint, an edge, a color, and one shared geometry. It renders a
`div` by default but can preserve another element or component as its host.

Surface owns only the material system. It does not add dimensions, padding,
layout, or elevation. The host stays transparent while material layers paint
beneath its content. It receives the resolved Appearance foreground unless
`style.color` makes another explicit choice.

## Color, radius, and material

`color` accepts an Appearance color and level such as `"primary:soft"`, or a
direct CSS color. Surface defaults to `"background:base"`.

`radius` accepts `xsmall`, `small`, `medium`, `large`, or `xlarge`; a pixel
number; or a CSS radius. Omission uses the Appearance radius, which is the same
result as the `medium` level.

Material customization remains grouped:

```tsx
<Surface
  color="background:soft"
  radius="large"
  material={{
    opacity: "large",
    backdrop: 18,
    grain: "small",
    grainAmount: 0.2,
    distortion: 24,
    saturation: 1.15,
  }}
  style={{ padding: 20 }}
>
  Customized material
</Surface>
```

Each material option accepts a numeric level derived from the corresponding
Appearance value or a direct number. The option changes the material, not the
content opacity or the host geometry. Omitted options inherit Appearance.

The edge is part of Surface and shares its resolved color and radius. Surface
keeps the edge and material aligned to the same host geometry.

## Selecting another host

`as` replaces the default `div` without adding a wrapper:

```tsx
import { useRef } from "react"
import { Surface } from "@phreshos/react-ui"

export default function NativeAction() {
  const ref = useRef<HTMLButtonElement>(null)

  return <Surface as="button" ref={ref} type="button">
    Native action
  </Surface>
}
```

This remains a native button; it does not gain React UI Button interaction.
Use [Button](/sdks/react-ui/components/button) when that higher-level behavior
is required.

A custom `SurfaceHost` must forward its ref and place the received `style` and
`children` on the same host element. Those three facts are what let Surface
preserve geometry, material, and native access without knowing the component's
identity.
