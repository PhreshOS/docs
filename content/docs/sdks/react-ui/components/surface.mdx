---
title: Surface
description: Put React UI material on one compatible host element.
---

`Surface` is the material-owning primitive of React UI. It combines a host
element, material paint, an edge, a color, and one shared geometry. It renders a
`div` by default. `as` selects another element or component that can receive
`style` and `children` on the same host.

<SurfaceShowcase />

`color` selects paint. `material` selects substance. `shadow` and `radius`
follow the shared Appearance contracts. Omission of `material` uses Appearance
defaults. `material={false}` uses the resolved color as a normal background.
