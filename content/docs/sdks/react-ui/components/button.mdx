title: Button

`Button` represents one action. Pointer activation, Enter, and Space all reach
the same `onPress` callback through React Aria, while React UI supplies the
material, color states, size, radius, and focus presentation.

The default color is `"default:base"`. `size` defaults to `medium` and derives
height, spacing, gap, and font size from Appearance. `radius` and `material`
follow the same contracts as other Surface-based controls.

Button chooses text contrast from its resting base color. Hover and pressed
states change the fill shade without recalculating that text color or changing
geometry.

`disabled` prevents both focus and activation. `pending` blocks activation but
keeps the Button focusable, so starting work does not destroy keyboard
position. Both default to `false`.

```tsx
<Button
  color="primary:base"
  size="large"
  material={{ opacity: 0.8 }}
  onPress={() => save()}
>
  Save
</Button>
```

The component renders a native `HTMLButtonElement`, forwards its ref, preserves
applicable React Aria button properties, and defaults `type` to `button`. Use
`type="submit"` when a form owns the action.
