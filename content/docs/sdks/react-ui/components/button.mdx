title: Button
description: Represent one accessible action with normalized interaction and Surface paint.
---

`Button` represents one action. Pointer activation, Enter, and Space all reach
the same `onPress` callback. React UI supplies the material, color states,
size, radius, and focus presentation.

<ButtonShowcase />

The default color is `"default:base"`. `size` defaults to `medium` and derives
height, spacing, gap, and font size from Appearance. `radius` and `material`
follow the same contracts as other Surface-based controls.

Button chooses text contrast from its resting base color. Hover and pressed
states change the fill shade without recalculating that text color or changing
geometry.

`disabled` prevents both focus and activation. `pending` blocks activation but
keeps the Button focusable. Both default to `false`. The host is a native
`HTMLButtonElement` and defaults `type` to `button`.
