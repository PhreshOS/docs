Use `Button` when pressing something does something: save, open, confirm.

```tsx
<Button color="primary" onPress={save}>Save</Button>
```

`onPress` fires for a click, a tap, and Enter or Space alike, so you need no
separate keyboard handling.

## Color

A Button is neutral (`default`) unless you give it a meaning:

```tsx
<Button>Cancel</Button>
<Button color="primary">Install</Button>
<Button color="danger">Delete</Button>
<Button color="danger:soft">Remove</Button>
```

Use `primary` for the one main action on a screen. The text color, hover,
press, and focus ring follow from the color. See
[Color](/sdks/react-ui/color).

## While something runs

`pending` ignores presses but keeps the Button focusable, so focus does not
jump away mid-action. `disabled` removes it from focus entirely.

```tsx
<Button color="primary" pending={saving} onPress={save}>
  {saving ? "Saving…" : "Save"}
</Button>

<Button disabled>Unavailable</Button>
```

## Icons and forms

An icon-only Button needs a name for screen readers:

```tsx
<Button aria-label="Close" onPress={close}><CloseIcon /></Button>
```

A Button is `type="button"` by default. Set `type="submit"` to submit a form.

## Props

| Prop | Default | Sets |
| --- | --- | --- |
| `onPress` | — | What happens when pressed |
| `color` | `"default"` | Its color |
| `size` | `"medium"` | Its size |
| `radius` | Scaled to its size | Its corners |
| `material`, `shadow` | `"basic"`, the Appearance shadow | Its Surface |
| `pending` | `false` | Ignore presses, keep focus |
| `disabled` | `false` | Off |
| `type` | `"button"` | The native button type |
