`@phreshos/core` defines the contracts shared across PhreshOS. A Program,
Process, Endpoint, Service, Window, or System capability has one meaning that
Client, Server, Node, and React all use.

Core does not connect to a System or own the capabilities those contracts
describe. Environment SDKs provide the implementations. The [Runtime](/runtime)
and [System](/system) sections explain what the contracts mean and how you
use them. This section is the Core package: configuration, Execute, and the
boundary parsers.

Environment SDKs depend on Core as a peer so an application has one set of
domain classes:

```ts
import { Program } from "@phreshos/core"
import { System } from "@phreshos/node"

const system = await System.connect()
const program = await system.program.find("notes")

console.log(program instanceof Program)
```

Core contains domain contracts and classes, authoring contracts used to
describe a Program project, and parsers used at untyped boundaries. It
contains no transport, persistence engine, command runner, or UI.
