`@phreshos/core` defines the contracts shared across PhreshOS. It gives a
Program, Process, Endpoint, Service, Window, or System capability one meaning
that Client, Server, Node, and React can all use without translating the domain
into environment-specific shapes.

Core does not connect to a System or own the capabilities described by those
contracts. Environment SDKs provide concrete implementations. Shared adapters
may compose those public implementations without creating another System
boundary.

<Callout title="Peer dependencies">
  Core has no peer dependencies.
</Callout>

Environment SDKs use Core as a peer dependency so an application has one set
of domain classes and contracts:

```ts
import { Program } from "@phreshos/core"
import { System } from "@phreshos/node"

const system = await System.connect()
const program = await system.program.find("terminal")

console.log(program instanceof Program)
```

## What Core provides

Core contains three related kinds of public value:

- domain contracts and classes shared by more than one environment;
- authoring contracts used to describe a Program project;
- immutable contract data and parsers used at untyped boundaries.

It contains no transport connection, persistence engine, command runner, or UI
implementation. That boundary keeps a change in how the System is reached from
changing what its domain objects mean.
