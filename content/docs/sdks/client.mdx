`@phreshos/client` implements the shared PhreshOS contracts for a Client
Endpoint executing inside a Desktop iframe.

```ts
import { context, desktop, system } from "@phreshos/client"
```

## Entry points

| Export | Contract |
| --- | --- |
| `context` | Current Client execution Context |
| `desktop` | Desktop containing the Client |
| `system` | Global System through Client authority |

## Context

`context` provides the executing Program and Process, paired Server Endpoint,
authoritative Window, local Window representation, immutable options,
communication, and permission requests.

## Authority

A Client can access its own Program, Processes belonging to that Program, and
Services belonging to that Program. System-wide capabilities and other
Programs require an applicable permission. Fabricating an identity or handle
cannot expand that authority.

## Domain handles

The SDK exports Core's `Program`, `Process`, `Endpoint`, `ServerEndpoint`,
`ClientEndpoint`, `Service`, `ServerService`, and `ClientService` constructors.
These preserve Core reference identity within this SDK context.

See [Security](/system/security) for the permission boundary and
[Communication](/runtime/communication) for requests, subscriptions, and event
semantics.
