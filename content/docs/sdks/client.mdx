`@phreshos/client` adapts the shared PhreshOS contracts to the Client Endpoint
executing inside a Desktop iframe.

```ts
import { context, desktop, system } from "@phreshos/client"
```

## Entry points

- `context` belongs to the executing Client Endpoint. It provides its Program,
  Process, paired Server Endpoint, Window, local Window representation, options,
  communication, and permission requests.
- `desktop` provides capabilities belonging to the current Desktop
  representation, including its surface and preferences.
- `system` exposes the shared System domain through the Client's authority
  boundary.

The SDK exports the Core `Program`, `Process`, `Endpoint`, and `Service` classes.
Repeated access within the same Client context preserves their handle identity.

## Authority

A Client can access its own Program, that Program's runtime entities and
resources, and Services belonging to that Program. System-wide capabilities
and other Programs require an applicable permission. Fabricating an identity
or handle cannot expand that authority.

See [Security](/system/security) for the permission boundary and
[Communication](/runtime/communication) for requests, subscriptions, and event
semantics.
