`@phreshos/node` implements the Core System contract for external Node.js code
and provides the Project authoring API.

## Connection

```ts
import { System } from "@phreshos/node"

const system = await System.connect()
const programs = await system.program.list()

await system.disconnect()
```

`System.connect()` is the connection factory, not part of the connected System
interface. The instance adds only `disconnect()` to the shared System contract.
The transport is not public API. The connection owns its handles and pending
operations; disconnecting ends that lifetime.

## Domain handles

The SDK exports Core's `Program`, `Process`, `Endpoint`, `ServerEndpoint`,
`ClientEndpoint`, `Service`, `ServerService`, and `ClientService` constructors.
These preserve Core reference identity within this SDK context.

## Project

```ts
import { Project, System } from "@phreshos/node"

const project = await Project.open()
const system = await System.connect()

const lifecycle = await project.start(system)

for await (const event of lifecycle) {
  console.log(event)
}
```

`Project` owns authoring concerns such as builds, development commands,
production definitions, installation, and packaging. The System receives only
the resulting runtime or installed Program definition.

| Operation | Result |
| --- | --- |
| `Project.open(source?)` | Load `phresh.config.ts` from a path or current directory |
| `Project.define(config, options?)` | Create a Project from an already loaded configuration |
| `manifest()` | Validated project package manifest |
| `productionDefinition()` | Production `ProgramDefinition` |
| `developmentDefinition()` | Development `ProgramDefinition` |
| `build()` | Run the optional author-owned build command |
| `start(system, options?)` | Promise of the production Process lifecycle generator |
| `dev(system, options?)` | Promise of the development Process lifecycle generator |
| `install(system)` | Promise of the Program installation generator |
| `pack()` | Archive, checksum, declaration paths, and SHA-256 digest |

`developmentDefinition()` and `productionDefinition()` return derived Program
definitions for custom composition. `dev()`, `start()`, and `install()` are
shortcuts that return the underlying lifecycle generators; await the shortcut
before iterating the returned generator.

`start()` and `dev()` accept immutable Process `options` and an abort `signal`.
Closing their returned generator, aborting that signal, or disconnecting the
System ends the attached lifecycle.

When a Client development declaration supplies a `startCommand` without a
fixed URL, Project selects an available local port and supplies
`PHRESHOS_CLIENT_PORT` and `PHRESHOS_CLIENT_BASE` to that command.

## Authority

Node retains the complete System contract. `fetch()` and `shell()` execute
locally when doing so preserves their observable contract, while their lifetime
remains tied to the System connection.
